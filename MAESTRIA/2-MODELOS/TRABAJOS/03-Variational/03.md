Find the stationary state equilibrium for an economy with

$$u(c_t^i, 1-h_t^i) = \log c_t^i + A \log(1-h_t^i)$$

$A = 1.72$, and

$$f(K_t, H_t) = \gamma K_t^{\theta} H_t^{1-\theta}$$

with $\gamma = 3$ and $\theta = .56$. Use $\beta = .98$ and $\delta = .06$. Find the numerical values of output, consumption, the capital stock, and labor supply in the stationary state using Matlab.



## Mathematical Derivation

### 1. The Representative Agent's Problem

The household maximizes:
$$\max_{\{c_t^i, h_t^i, k_{t+1}^i\}} \sum_{t=0}^{\infty} \beta^t [\log c_t^i + A \log(1-h_t^i)]$$

Subject to the budget constraint:
$$c_t^i + k_{t+1}^i = w_t h_t^i + r_t k_t^i + (1-\delta)k_t^i$$

### 2. First-Order Conditions

Setting up the Lagrangian:
$$\mathcal{L} = \sum_{t=0}^{\infty} \beta^t \left[\log c_t^i + A \log(1-h_t^i) - \lambda_t(c_t^i + k_{t+1}^i - w_t h_t^i - r_t k_t^i - (1-\delta)k_t^i)\right]$$

The first-order conditions are:

**FOC for $c_t^i$:**
$$\frac{\partial \mathcal{L}}{\partial c_t^i} = \frac{1}{c_t^i} - \lambda_t = 0 \Rightarrow \lambda_t = \frac{1}{c_t^i}$$

**FOC for $h_t^i$:**
$$\frac{\partial \mathcal{L}}{\partial h_t^i} = -\frac{A}{1-h_t^i} + \lambda_t w_t = 0$$

Substituting $\lambda_t = \frac{1}{c_t^i}$:
$$\frac{A}{1-h_t^i} = \frac{w_t}{c_t^i}$$

**FOC for $k_{t+1}^i$:**
$$\frac{\partial \mathcal{L}}{\partial k_{t+1}^i} = -\lambda_t + \beta \lambda_{t+1}[r_{t+1} + (1-\delta)] = 0$$

Substituting $\lambda_t = \frac{1}{c_t^i}$:
$$\frac{1}{c_t^i} = \beta \frac{1}{c_{t+1}^i}[r_{t+1} + (1-\delta)]$$

### 3. Competitive Equilibrium

In competitive equilibrium:
- $w_t = f_H(K_t, H_t) = \gamma(1-\theta)K_t^{\theta}H_t^{-\theta}$
- $r_t = f_K(K_t, H_t) = \gamma\theta K_t^{\theta-1}H_t^{1-\theta}$

After aggregation ($K_t = k_t^i$, $H_t = h_t^i$, $C_t = c_t^i$), the equilibrium conditions become:

**Labor-leisure condition:**
$$\frac{A}{1-H_t} = \frac{f_H(K_t, H_t)}{C_t}$$

**Euler equation:**
$$\frac{C_t}{C_{t+1}} = \beta[f_K(K_{t+1}, H_{t+1}) + (1-\delta)]$$

**Resource constraint:**
$$C_t + K_{t+1} = f(K_t, H_t) + (1-\delta)K_t$$

### 4. Stationary State

In the stationary state, all variables are constant: $K_t = K_{t+1} = \bar{K}$, $H_t = H_{t+1} = \bar{H}$, $C_t = C_{t+1} = \bar{C}$.

The stationary state conditions become:

**From the Euler equation:**
$$1 = \beta[f_K(\bar{K}, \bar{H}) + (1-\delta)]$$
$$f_K(\bar{K}, \bar{H}) = \frac{1}{\beta} - (1-\delta)$$

Substituting the production function:
$$\gamma\theta \bar{K}^{\theta-1}\bar{H}^{1-\theta} = \frac{1}{\beta} - (1-\delta)$$

**From the labor-leisure condition:**
$$\frac{A\bar{C}}{1-\bar{H}} = f_H(\bar{K}, \bar{H})$$

Substituting the production function:
$$\frac{A\bar{C}}{1-\bar{H}} = \gamma(1-\theta)\bar{K}^{\theta}\bar{H}^{-\theta}$$

**From the resource constraint:**
$$\bar{C} = f(\bar{K}, \bar{H}) - \delta\bar{K}$$
$$\bar{C} = \gamma\bar{K}^{\theta}\bar{H}^{1-\theta} - \delta\bar{K}$$

### 5. System of Equations

We have three equations in three unknowns $(\bar{K}, \bar{H}, \bar{C})$:

1. **Euler equation:**
   $$\gamma\theta \bar{K}^{\theta-1}\bar{H}^{1-\theta} = \frac{1}{\beta} - (1-\delta)$$

2. **Labor-leisure condition:**
   $$\frac{A\bar{C}}{1-\bar{H}} = \gamma(1-\theta)\bar{K}^{\theta}\bar{H}^{-\theta}$$

3. **Resource constraint:**
   $$\bar{C} = \gamma\bar{K}^{\theta}\bar{H}^{1-\theta} - \delta\bar{K}$$

### 6. Numerical Solution

With the given parameters:
- $A = 1.72$
- $\gamma = 3$
- $\theta = 0.56$
- $\beta = 0.98$
- $\delta = 0.06$

The target for $f_K$:
$$f_K = \frac{1}{0.98} - (1-0.06) = 1.0204 - 0.94 = 0.0804$$

## MATLAB Code

```matlab
% Parameters
A = 1.72;
gamma = 3;
theta = 0.56;
beta = 0.98;
delta = 0.06;

%system of equations
% x(1) = K, x(2) = H, x(3) = C
F = @(x) [
    % Euler
    gamma * theta * x(1)^(theta-1) * x(2)^(1-theta) - (1/beta - (1-delta));
    % Labor-leisure condition
    (A * x(3))/(1 - x(2)) - gamma * (1-theta) * x(1)^theta * x(2)^(-theta);
    %Resource constraint:
    gamma * x(1)^theta * x(2)^(1-theta) - delta * x(1) - x(3)
];

% Initial guess [K, H, C]
x0 = [10; 0.3; 2];

options = optimoptions('fsolve', 'Display', 'iter', 'TolFun', 1e-10, 'TolX', 1e-10);
[x_sol, fval, exitflag] = fsolve(F, x0, options);

K_bar = x_sol(1);
H_bar = x_sol(2);
C_bar = x_sol(3);
Y_bar = gamma * K_bar^theta * H_bar^(1-theta);

% Display results
fprintf('\nStationary State Values:\n');
fprintf('=====================================\n');
fprintf('Capital stock (K):      %.4f\n', K_bar);
fprintf('Labor supply (H):       %.4f\n', H_bar);
fprintf('Consumption (C):        %.4f\n', C_bar);
fprintf('Output (Y):             %.4f\n', Y_bar);
fprintf('Investment (I):         %.4f\n', delta * K_bar);
fprintf('Capital-output ratio:   %.4f\n', K_bar/Y_bar);
fprintf('Consumption-output ratio: %.4f\n', C_bar/Y_bar);
fprintf('Savings rate:           %.4f\n', 1 - C_bar/Y_bar);

% Verify the solution
fprintf('\nVerification (should be close to zero):\n');
fprintf('=====================================\n');
errors = F(x_sol);
fprintf('Euler equation error:        %.2e\n', errors(1));
fprintf('Labor-leisure error:         %.2e\n', errors(2));
fprintf('Resource constraint error:   %.2e\n', errors(3));

% Check economic conditions
fprintf('\nEconomic Checks:\n');
fprintf('=====================================\n');
fprintf('Marginal product of capital: %.4f\n', gamma * theta * K_bar^(theta-1) * H_bar^(1-theta));
fprintf('Required return (1/beta - 1 + delta): %.4f\n', 1/beta - 1 + delta);
fprintf('Marginal product of labor:   %.4f\n', gamma * (1-theta) * K_bar^theta * H_bar^(-theta));
fprintf('Wage rate:                   %.4f\n', gamma * (1-theta) * K_bar^theta * H_bar^(-theta));
fprintf('Rental rate:                 %.4f\n', gamma * theta * K_bar^(theta-1) * H_bar^(1-theta));
