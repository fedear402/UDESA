### The Household

**Maximization problem**

$$\max_{\{c_t,h_t,k_{t+1},b_t\}} E_t \sum_{t=0}^{\infty} \beta^t [\ln c_t + Bh_t]$$

where

$$B = \frac{A\ln(1-h_0)}{h_0}$$

Budget constraint with $b_t$ = holdings of risk free international bonds measured in real terms. $r^*_{t}$ is foreign interest rate
$$b_t + k_{t+1} + \frac{\kappa}{2}(k_{t+1} - k_t)^2 + c_t = w_t h_t + r_t k_t + (1-\delta)k_t + (1+r^*_{t-1})b_{t-1}$$

$$\lim_{t\to\infty} \frac{b_t}{\Pi_{t=0}^{\infty}(1+r^*_{t})} = \lim_{t\to\infty} \beta^t b_t = 0$$
Instead of assuming a constant net foreign interest rate $r^* = 1/\beta - 1$ like we did in class, we will assume that the interest rate follow a random process:
$$
r^{*}_{t} = \phi r^{*}+(1-\phi)r_{t-1}^{*} + \varepsilon_{t}^{r} 
$$


### Solving the households problem
$$
\mathcal{L} = E_{0} \sum_{t=0}^{\infty} \beta ^{t} [\ln c_t + Bh_t] + \beta ^{t} \lambda _{t} [w_t h_t + r_t k_t + (1-\delta)k_t + (1+r^*_{t-1})b_{t-1} - b_t - k_{t+1} - \frac{\kappa}{2}(k_{t+1} - k_t)^2 - c_t  ]
$$

$$
\frac{ \partial \mathcal{L} }{ \partial c_{t} } = \frac{1}{c_{t}} - \lambda _{t} = 0 \implies \boxed{\frac{1}{c_{t}} = \lambda _{t} }
$$
$$
\frac{ \partial \mathcal{L} }{ \partial h_{t} }  = B+\lambda _{t}w_{t} = 0  \implies B = -\lambda _{t}w_{t}
$$
Using $\frac{1}{c_{t}} = \lambda _{t}$, we obtain:
$$
\boxed{B = -\frac{w_t}{c_t}}
$$
Then, for capital:

$$
\frac{ \partial \mathcal{L} }{ \partial k_{t+1} }  = \beta ^{t}\left[ -\lambda _{t}  -\lambda _{t} \kappa \left( k_{t+1}-k_{t} \right)   \right]  + \beta ^{t+1} \mathbb{E}_{0}\left[ \lambda_{t+1} (r_{t+1}+1-\delta) +\lambda _{t+1} \kappa \left( k_{t+2}-k_{t+1} \right) ] \right]  = 0
$$
$$
\beta  \mathbb{E}_{0}\left[ \lambda_{t+1} (r_{t+1}+1-\delta) +\lambda _{t+1} \kappa \left( k_{t+2}-k_{t+1} \right) ] \right]  =\lambda _{t} \left[ 1  + \kappa \left( k_{t+1}-k_{t} \right)   \right] 
$$
Using $\frac{1}{c_{t}} = \lambda _{t}$, we obtain:
$$
\boxed{\beta  \mathbb{E}_{0}\left[ \frac{1}{c_{t+1}} (r_{t+1}+1-\delta) +\frac{1}{c_{t+1}} \kappa \left( k_{t+2}-k_{t+1} \right) ] \right]  =\frac{1}{c_{t}} \left[ 1  + \kappa \left( k_{t+1}-k_{t} \right)   \right] }
$$

For bonds:
$$
\frac{ \partial \mathcal{L} }{ \partial b_{t} }  = \mathbb{E}_{0}[\beta ^{t+1}\lambda _{t+1}(1+r_{t}^{*}) ]- \beta ^{t}\lambda _{t} =0
$$
$$
\beta\mathbb{E}_{0}[\lambda _{t+1}(1+r_{t}^{*}) ]=\lambda _{t}
$$
Using $\frac{1}{c_{t}} = \lambda _{t}$, we obtain:
$$
\boxed{\beta\mathbb{E}_{0}[\frac{1}{c_{t+1}}(1+r_{t}^{*}) ]= \frac{1}{c_{t}}}
$$



### Household first order conditions and budget constraints:

$$
\begin{flalign}
&B = -\frac{w_t}{c_t} \\
&\beta\mathbb{E}_{0}[\frac{1}{c_{t+1}}(1+r_{t}^{*}) ]= \frac{1}{c_{t}} \\
&\beta  \mathbb{E}_{0}\left[ \frac{1}{c_{t+1}} (r_{t+1}+1-\delta) +\frac{1}{c_{t+1}} \kappa \left( k_{t+2}-k_{t+1} \right) ] \right]  =\frac{1}{c_{t}} \left[ 1  + \kappa \left( k_{t+1}-k_{t} \right)   \right] \\
&b_t + k_{t+1} + \frac{\kappa}{2}(k_{t+1} - k_t)^2 + c_t = w_t h_t + r_t k_t + (1-\delta)k_t + (1+r^*_{t-1})b_{t-1} \\
\end{flalign}
$$

Where these conditions also have to hold:
$$
r^{*}_{t} = \phi r^{*}+(1-\phi)r_{t-1}^{*} + \varepsilon_{t}^{r} 
$$
and

$$\lim_{t\to\infty} \frac{b_t}{\Pi_{t=0}^{\infty}(1+r^*_{t})} = 0$$






# The domestic firms

The production function

$$f(\lambda_t, k_t, h_t) = \lambda_t k_t^{\theta} h_t^{1-\theta}$$

where

$$\lambda_{t+1} = \gamma\lambda_t + \varepsilon_{t+1}$$

with $0 < \gamma < 1$ and $E_t\varepsilon_{t+1} = 1 - \gamma$.

Conditions for real wages and rentals (factor market equilibrium)

$$r_t = \theta\lambda_t k_t^{\theta-1} h_t^{1-\theta}$$

and

$$w_t = (1-\theta) \lambda_t k_t^{\theta} h_t^{-\theta}$$

# Model 2: Log-linear version

**The full log linear model is**

$$0 = \tilde{C}_t - \tilde{w}_t$$

$$0 = \tilde{C}_t - E_t\tilde{C}_{t+1}$$

$$0 = \tilde{C}_t - E_t\tilde{C}_{t+1} + \beta\bar{r}E_t\tilde{r}_{t+1} - \beta\kappa\bar{K} E_t\tilde{K}_{t+2} - (1+\beta) \kappa\bar{K}\tilde{K}_{t+1} + \kappa\bar{K}\tilde{K}_t$$

$$0 = \bar{B}\tilde{B}_t + \bar{K}\tilde{K}_{t+1} + \bar{C}\tilde{C}_t - \bar{w}\bar{H}\tilde{w}_t - \bar{w}\bar{H}\tilde{H}_t - \bar{r}\bar{K}\tilde{r}_t - [\bar{r} + (1-\delta)] \bar{K}\tilde{K}_t - (1+r^*)\bar{B}\tilde{B}_{t-1}$$

$$0 = \tilde{\lambda}_t + (\theta - 1) \tilde{K}_t + (1-\theta) \tilde{H}_t - \tilde{r}_t$$

$$0 = \tilde{\lambda}_t + \theta\tilde{K}_t - \theta\tilde{H}_t - \tilde{w}_t$$

---

## Model 2: Log-linear version

This system can be reduced to the two equation system

$$0 = \frac{\gamma(1-\gamma)}{(1-\theta)} \tilde{\lambda}_t + \xi \left[\beta E_t\tilde{K}_{t+3} - (1+2\beta) E_t\tilde{K}_{t+2} + (2+\beta) \tilde{K}_{t+1} - \tilde{K}_t\right]$$

and

$$0 = \bar{B}\tilde{B}_t - \left((1-\gamma) [\bar{w}\bar{H} + \bar{r}\bar{K}] - \frac{\gamma\bar{C}}{(1-\theta)}\right) \tilde{\lambda}_t$$

$$- \left([\bar{C} + (1-\theta) [\bar{w}\bar{H} + \bar{r}\bar{K}]] \xi (1-\beta) - \bar{K}\right) \tilde{K}_{t+1}$$

$$+ \left([\bar{C} + (1-\theta) [\bar{w}\bar{H} + \bar{r}\bar{K}]] \xi (1-\beta) - [\bar{r} + (1-\delta)] \bar{K} - \bar{w}\bar{H}\right) \tilde{K}_t - (1+r^*)\bar{B}\tilde{B}_{t-1}$$

**Note: this system is hierarchical.** First find $\tilde{K}_{t+1}$ then find use that $\tilde{K}_{t+1}$ to find $\tilde{B}_t$.

---

## A hierarchical solution

The solution to this hierarchical probem is a pair of matrices $P$ and $Q$ of the form

$$\begin{bmatrix} \tilde{K}_{t+1} \\ \tilde{B}_t \end{bmatrix} = \begin{bmatrix} P_{11} & 0 \\ P_{21} & P_{22} \end{bmatrix} \begin{bmatrix} \tilde{K}_t \\ \tilde{B}_{t-1} \end{bmatrix} + \begin{bmatrix} Q_1 \\ Q_2 \end{bmatrix} \tilde{\lambda}_t$$

The 0 where $P_{12}$ should be is because $\tilde{B}_{t-1}$ is not a state variable for finding the values of $\tilde{K}_{t+1}$

That $P_{22}$ is there tells us that both $\tilde{K}_t$ and $\tilde{B}_{t-1}$ are needed to find $\tilde{B}_t$

Note that the matrix $P$ is triangular. The matrix for the solution of a hierarchical will always have this shape

---

## Model 2: Log-linear version (solving)

We first solve for a policy function for $\tilde{K}_{t+1}$ of the form

$$\tilde{K}_{t+1} = P_{11}\tilde{K}_t + Q_1\tilde{\lambda}_t$$

Applying this equation twice to get $E_t\tilde{K}_{t+2}$ in terms of $\tilde{K}_t$ and $\tilde{\lambda}_t$,

$$E_t\tilde{K}_{t+2} = P_{11}\tilde{K}_{t+1} + Q_1E_t\tilde{\lambda}_{t+1}$$

$$= P_{11} [P_{11}\tilde{K}_t + Q_1\tilde{\lambda}_t] + Q_1\gamma\tilde{\lambda}_t$$

$$= (P_{11})^2 \tilde{K}_t + Q_1 (P_{11} + \gamma) \tilde{\lambda}_t$$

and applying it again to get $E_t\tilde{K}_{t+3}$ in terms of $\tilde{K}_t$ and $\tilde{\lambda}_t$,

$$E_t\tilde{K}_{t+3} = P_{11}\tilde{K}_{t+2} + Q_1E_t\tilde{\lambda}_{t+2}$$

$$= P_{11} [P_{11}\tilde{K}_{t+1} + Q_1\tilde{\lambda}_{t+1}] + Q_1\gamma\tilde{\lambda}_{t+1}$$

$$= P_{11} [P_{11} [P_{11}\tilde{K}_t + Q_1\tilde{\lambda}_t] + Q_1\gamma\tilde{\lambda}_t] + Q_1\gamma^2\tilde{\lambda}_t$$

$$= (P_{11})^3 \tilde{K}_t + Q_1 \left((P_{11})^2 + \gamma P_{11} + \gamma^2\right) \tilde{\lambda}_t$$

---

## Model 2: Log-linear version (solving)

Put these expressions into the capital equation and get

$$0 = \gamma (1-\gamma) \tilde{\lambda}_t + \xi \left[\beta P_{11}^3 - (1+2\beta) P_{11}^2 + (2+\beta) P_{11} - 1\right] \tilde{K}_t$$

$$+\xi Q_1 \left[\beta (P_{11})^2 + \beta^2\gamma P_{11} + \beta^2\gamma^2 + P_{11} + \gamma - 2 - \beta\right] \tilde{\lambda}_t$$

For this to hold for all $\tilde{K}_t$ and $\tilde{\lambda}_t$, need to solve the cubic equation,

$$\beta P_{11}^3 - (1+2\beta) P_{11}^2 + (2+\beta) P_{11} - 1 = 0$$

and then

$$\frac{\gamma (1-\gamma)}{\xi (\theta - 1)} = Q_1 \left[\beta \left(P_{11}^2 + \gamma P_{11} + \gamma^2\right) - (1+2\beta) (P_{11} + \gamma) + (2+\beta)\right]$$

---

## Model 2: Log-linear version (solving)

The solution for this cubic equation is simple and the values for $P_{11}$ are

$$P_{11} = 1 \text{ or } P_{11} = \frac{1}{\beta}$$

and then $Q_1$ is either

$$Q_1 = -\frac{\gamma}{\xi (1-\theta) (1-\beta\gamma)} \text{ or } Q_1 = -\frac{\gamma}{\xi (1-\theta) \beta (1-\gamma)}$$

Note

$$P_{21} = \frac{[\bar{r} - \delta)] \bar{K} + \bar{w}\bar{H}}{\bar{B}}$$

and

$$P_{22} = 1 + r^*$$

**Problem: solution either a random walk or explosive** $\Rightarrow$ so our initial assumption of a SS not valid

## Closing the open economy

**Interest rates and some measure of "country risk"**

- **Assume:** foreign interest rate charged is a function of total international debt (or savings) of a country

- **Data:** this need not be true.
  • In 2001, Argentine's government's debt was approximately equal to Argentina's citizens private savings outside the country in dollars
  • According to the above rule, foreign interest rate should then have been for a country with no net foreign debt

- **Not true because** the legal standing of private savings in foreign countries is different than the government's debt. Foreign creditors to the government can (with certain exceptions) foreclose on the government's property outside the country. Government owned firms can face the same problem. (Which is why Aerolineas Argentina rented the planes it flew outside the country)

- Note that private debt in foreign currency can be a source of macro instability: the south asia crisis in late 1990's.

---

## The interest rate function

We use a simple functional form that captures our assumption:

$$r_t^* = r^* - aB_t$$

**Household first order conditions**

$$B = -\frac{w_t}{C_t}$$

$$\frac{1}{C_t} = \beta E_t \frac{1}{C_{t+1}}(1 + r^* - aB_t)$$

$$\frac{1}{\beta}(1 + \kappa (K_{t+1} - K_t)) = E_t \frac{C_t}{C_{t+1}} [r_{t+1} + (1-\delta) + \kappa (K_{t+2} - K_{t+1})]$$

$$B_t + K_{t+1} + C_t = w_t H_t + r_t K_t + (1-\delta)K_t - \frac{\kappa}{2}(K_{t+1} - K_t)^2 + (1 + r^* - aB_{t-1})B_{t-1}$$

---

## Closing the open economy: Stationary states

In a stationary state, $\bar{C} = C_t = C_{t+1}$ so the second equation is

$$\frac{1}{\bar{C}} = \beta\frac{1}{\bar{C}}(1 + r^* - a\bar{B}),$$

or

$$\bar{B} = \frac{r^* + 1 - \frac{1}{\beta}}{a}.$$

In the stationary state, the holding of foreign bonds or debt is exactly that which makes the real gross interest rate the country pays (or receives) for foreign borrowing (or lending) equal to $1/\beta$. So the whether it is lending or borrowint is determined by the values of $a$ and $r^*$.

---

## Closing the open economy: Log-linear version

$$0 = \tilde{C}_t - \tilde{w}_t$$

$$0 = \tilde{C}_t - E_t\tilde{C}_{t+1} - \beta a\bar{B}\tilde{B}_t$$

$$0 = \beta\bar{r}E_t\tilde{r}_{t+1} + \tilde{C}_t - E_t\tilde{C}_{t+1} + \beta\kappa\bar{K} E_t\tilde{K}_{t+2} - (1+\beta) \kappa\bar{K}\tilde{K}_{t+1} + \kappa\bar{K}\tilde{K}_t$$

$$0 = \bar{B}\tilde{B}_t + \bar{K}\tilde{K}_{t+1} + \bar{C}\tilde{C}_t - \bar{w}\bar{H} \left(\tilde{w}_t + \tilde{H}_t\right)$$

$$-\bar{r}\bar{K}\tilde{r}_t - \frac{\bar{K}}{\beta}\tilde{K}_t - \left((1+r^*) \bar{B} - 2a\bar{B}^2\right) \tilde{B}_{t-1}$$

$$0 = \tilde{\lambda}_t + (\theta - 1) \tilde{K}_t + (1-\theta) \tilde{H}_t - \tilde{r}_t$$

$$0 = \tilde{\lambda}_t + \theta\tilde{K}_t - \theta\tilde{H}_t - \tilde{w}_t$$

## Closing the open economy: Log-linear version

Let $x_t = [\tilde{K}_{t+1}, \tilde{B}_t]'$ be the vector of state variables

$y_t = [\tilde{C}_t, \tilde{r}_t, \tilde{w}_t, \tilde{H}_t]'$ be the vector of jump variables

$z_t = [\tilde{\lambda}_t]'$ be the one stochastic variable

Notice the difference in the response of $\tilde{B}_t$ in the two examples given.

When the country holds foreign bonds, when $\bar{B}$ is positive, it buys more foreign bonds and more capital (diversifies) as a response to the positive technology shock.

When the country has borrowed in foreign currency, when $\bar{B}$ is negative, it reduces its foreign debt as a response to a positive technology shock so that $\tilde{B}_t$ is negative but $\bar{B}\tilde{B}_t$ is positive.
