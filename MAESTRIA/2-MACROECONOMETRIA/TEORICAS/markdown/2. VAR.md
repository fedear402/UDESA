## Introduction

▶ A VAR is an autoregressive model for a vector of variables.

▶ **Advantages of VARs over simple regression models:**
 ▶ Every variable is endogenous (no incredible exogeneity assumptions).  
 ▶ Every variable depends on the others (no incredible exclusion restrictions).  
 ▶ Simple to estimate and use.  
 ▶ Allows to summarize the (auto)covariance structure in the data.

▶ **General disadvantages:**
 ▶ It is a reduced-form model: no economic interpretation of is possible without further assumptions.  
 ▶ Linearity.

---

## A simple example

▶ Consider two variables $(y_{1,t}, y_{2,t})$ with one lag,

$$y_{1,t} = \pi_1 + \phi_{11}y_{1,t-1} + \phi_{12}y_{2,t-1} + e_{1,t},$$
$$y_{2,t} = \pi_2 + \phi_{21}y_{1,t-1} + \phi_{22}y_{2,t-1} + e_{2,t},$$

where $e_{1,t}$ and $e_{2,t}$ are WN, possibly correlated with each other.

▶ We can write this system with vectors and matrices,

$$\begin{bmatrix} y_{1,t} \\ y_{2,t} \end{bmatrix} = \begin{bmatrix} \pi_1 \\ \pi_2 \end{bmatrix} + \begin{bmatrix} \phi_{11} & \phi_{12} \\ \phi_{21} & \phi_{22} \end{bmatrix} \begin{bmatrix} y_{1,t-1} \\ y_{2,t-1} \end{bmatrix} + \begin{bmatrix} e_{1,t} \\ e_{2,t} \end{bmatrix}$$

$$\underbrace{}_{\equiv y_t} \quad \underbrace{}_{\equiv \Pi} \quad \underbrace{}_{\equiv \Phi} \quad \underbrace{}_{\equiv y_{t-1}} \quad \underbrace{}_{\equiv e_t}$$

---

## A simple model

▶ Thus, a VAR(1) model for the vector $y_t$ is,

$$y_t = \Pi + \Phi y_{t-1} + e_t$$

This as a **reduced-form VAR** (more in following classes).

▶ **Properties of $e_t$:**

$$E(e_t) = E\begin{bmatrix} e_{1,t} \\ e_{2,t} \end{bmatrix} = \begin{bmatrix} 0 \\ 0 \end{bmatrix} = 0,$$

$$V(e_t) = E(e_t e_t') = \begin{bmatrix} V(e_{1,t}) & Cov(e_{1,t}, e_{2,t}) \\ Cov(e_{1,t}, e_{2,t}) & V(e_{2,t}) \end{bmatrix} = \Sigma,$$

and,
$$Cov(e_t, e_j) = E(e_t e_j') = 0 \text{ if } t \neq j.$$

This is the vector version of a WN.

---

## VAR(p)

▶ A VAR(p) model

$$y_t = \Pi + \Phi_1 y_{t-1} + ... + \Phi_p y_{t-p} + e_t, \quad e_t \sim i.i.d.(0, \Sigma)$$

where
▶ $y_t$ is an $m \times 1$ vector (i.e. $m$ variables).  
▶ $\Pi$ is $m \times 1$.  
▶ $\Phi_j$ are $m \times m$ matrices for each $j = 1, ..., p$  
▶ $\Sigma_u$ is a p.s.d., $m \times m$ matrix.

▶ **Notice the number of parameters:** with $m$ variables and $p$ lags:

$$m + m^2 p + \frac{m(m + 1)}{2}$$

▶ We can also use the matrix polynomial in the lag operator and write $\Phi(L)y_t = \Pi + e_t$,  
where $\Phi(L) = I - \Phi_1 L - ... - \Phi_p L^p$.

---

## Writing a VAR(p) as a VAR(1)

▶ The VAR(p) can be written as a VAR(1) in an expanded system:

$$\begin{bmatrix} y_t \\ y_{t-1} \\ \vdots \\ y_{t-p+1} \end{bmatrix} = \begin{bmatrix} \Pi \\ 0 \\ \vdots \\ 0 \end{bmatrix} + \begin{bmatrix} \Phi_1 & \Phi_2 & \cdots & \Phi_p \\ I_m & 0 & \cdots & 0 \\ 0 & I_m & \cdots & 0 \\ 0 & \cdots & I_m & 0 \end{bmatrix} \begin{bmatrix} y_{t-1} \\ y_{t-2} \\ \vdots \\ y_{t-p} \end{bmatrix} + \begin{bmatrix} e_t \\ 0 \\ \vdots \\ 0 \end{bmatrix}$$

or
$$\mathbf{y}_t = \mathbf{\Pi} + \mathbf{\Phi}\mathbf{y}_{t-1} + \mathbf{e}_t.$$

▶ This is the VAR's **companion form**, useful to compute estimators, forecast, moments, etc.

▶ Another alternative (multiply companion form by $S = [I_m, 0, ...0]$):

$$y_t = \Pi + \Phi_1 y_{t-1} + e_t.$$

$\Phi_1$ collect the first $m$ rows of $\mathbf{\Phi}$ (i.e. $y_t = S\mathbf{y}_t$, $\Pi = S\mathbf{\Pi}$, $\Phi_1 = S\mathbf{\Phi}$).

## Wold Representation

▶ **Covariance-stationarity for vector processes:**
 ▶ $E\{y_t\} = \mu$ (independent of $t$).  
 ▶ $E\{(y_t - \mu)(y_{t-h} - \mu)'\} = \Gamma_h$ (independent of $t$).

▶ **Wold Representation theorem:** Under linearity and stationarity, any vector of time series $y_t$ can be expressed as a VMA($\infty$)

$$y_t = \mu + \sum_{j=0}^{\infty} \Theta_j e_{t-j} = \mu + \Theta(L)e_t,$$

▶ With this
$$E\{y_t\} = \mu, \quad \Gamma_h = \sum_{i=0}^{\infty} \Theta_{i+h}\Sigma\Theta_i'.$$

▶ **VMA($\infty$) representation of a VAR(1)** (or VAR(p) with companion form)

$$y_t = \Pi + \Phi y_{t-1} + e_t = \Pi + \Phi(\Pi + \Phi y_{t-2} + e_{t-1}) + e_t$$
$$= \Pi + \Phi(\Pi + \Phi(\Pi + \Phi y_{t-3} + e_{t-2}) + e_{t-1}) + e_t = ...$$
$$= \sum_{j=0}^{\infty} \Phi^j \Pi + \lim_{j \to \infty} \Phi^j y_{t-j} + \sum_{j=0}^{\infty} \Phi^j e_{t-j} =$$
$$= (1 - \Phi)^{-1}\Pi + \sum_{j=0}^{\infty} \Phi^j e_{t-j}.$$

**Comparison with $MA(\infty)$:**
$$\mu = (1 - \Phi)^{-1}\Pi, \quad \Theta_j = \Phi^j.$$

▶ **Stationarity:** $\lim_{j \to \infty} \Phi^j = 0$. This, in turn requires $|eig(\Phi)| < 1$ (i.e. the real part of all eigenvalues less than one in modulus).

▶ Thus, a VAR(p) can approximate the true VMA($\infty$). The key is to properly select $p$.

## Estimation

▶ For estimation we require a **weak exogeneity assumption**

$$E(e_t|y_{t-1}, y_{t-2}, ...) = 0.$$

If $e_t$ is truly i.i.d. this assumption is satisfied.

▶ **OLS estimation:** Using,
$$y_t = \Pi + \Phi_1 y_{t-1} + e_t.$$

we have,
$$\hat{\Phi}_1 = \left(\sum_{t=1}^T y_t y_{t-1}'\right) \left(\sum_{t=1}^T y_{t-1} y_{t-1}'\right)^{-1}, \quad \hat{\Pi} = \bar{y} - \hat{\Phi}_1 \bar{y}$$

▶ It can be shown that this is equivalent to estimate the VAR equation-by-equation by OLS.

---

## Estimation

▶ Once, we get $\hat{\Phi}_1$, we can construct $\hat{e}_t = y_t - \hat{\Pi} - \hat{\Phi}_1 y_{t-1}$ and compute

$$\hat{\Sigma} = \frac{1}{T - (p + 1)m} \sum_{t=1}^T \hat{e}_t \hat{e}_t'.$$

▶ If we further assume that $e_t \sim N(0, \Sigma)$, we can also estimate the parameters by Maximum Likelihood (MLE).

▶ It can be shown that in this framework the MLE estimate of $\hat{\Phi}_1$ is equivalent to OLS.

---

## Estimation

▶ **Properties:** under these assumptions (particularly stationarity), OLS/MLE is consistent and asymptotically normal.

▶ **Extension:** Add deterministic or strictly exogenous variables,

$$y_t = \Pi + \Phi_1 y_{t-1} + D z_t + e_t.$$

where $E(e_t|..., z_{t+1}, z_t, z_{t-1}, ...) = 0$. This can also be estimated by OLS. Examples:
▶ Dummies.  
▶ Deterministic trends.  
▶ World variables for small economies.

## Specification - How to choose the lag length?

▶ **Notation:** $\hat{\Sigma}_p$ is the variance of the residual with $p$ lags.

▶ **Likelihood Ratio test:**
$$LR_{p,p-1} = 2(l_p - l_{p-1}) = T[\ln(|\hat{\Sigma}_{p-1}|) - \ln(|\hat{\Sigma}_p|)]$$

Asymptotically, $LR_{p,p-1}$ is distributed as $\chi^2(m)$.

▶ In short samples, $LR$ is biased, so we can use:
$$LR_{p,p-1} = (T - pm)[\ln(|\hat{\Sigma}_{p-1}|) - \ln(|\hat{\Sigma}_p|)]$$

▶ We can apply this test sequentially (general to particular):
 ▶ Choose a maximum value $\bar{p}$.  
 ▶ Test a VAR($\bar{p}$) against VAR($\bar{p}$-1).  
 ▶ If do not reject, Test a VAR($\bar{p}$-1) against VAR($\bar{p}$-2).  
 ▶ Continue until rejection.  
 ▶ Why not from particular to general?

---

## Specification - How to choose the lag length?

### Information criteria

▶ **AIC criterion:** choose $p$ to minimize $\ln(|\hat{\Sigma}_p|) + \frac{2pm^2}{T}$.

▶ **BIC/SIC criterion:** choose $p$ to minimize $\ln(|\hat{\Sigma}_p|) + pm^2 \frac{\ln(T)}{T}$.

▶ **HQC criterion:** choose $p$ to minimize $\ln(|\hat{\Sigma}_p|) + 2pm^2 \frac{\ln(\ln(T))}{T}$.

▶ To implement all these criteria, choose a maximum value $\bar{p}$ and perform all the estimates using the same sample that excludes the first $\bar{p}$ observations.

▶ **Be careful:**
 ▶ All these need to be calculated with the same sample in the left-hand-side: use the sample $\bar{p} + 1, ..., T$ in all regression for evaluation.  
 ▶ Here, $\hat{\Sigma} = \frac{1}{T} \sum_{t=1}^T \hat{e}_t \hat{e}_t'$ (i.e. no correction for degrees of freedom).

---

## Specification - How to choose the lag length?

▶ These criteria trade-off the fit of the model $(|\hat{\Sigma}_p|)$ with the number of parameters $(2pm^2)$, for a given sample size $T$.

## Specification

▶ **Which criteria to use?**
 ▶ **Consistency of a model selection criteria:** A criteria is consistent if, as the sample size goes to infinity, the criteria selects the correct model with probability 1.

▶ It can be shown that LR and AIC are not consistent, but HQC and BIC are. Thus, LR and AIC will overestimate $p$ with positive probability.

▶ Ivanov and Kilian (2006) study the performance of these criteria in small samples. Overall, HQC seems to be the best.

## Forecast

▶ We want to compute the forecast
$$E \{y_{T+h}|y_T, y_{T-1}, ...\} \equiv y_{T+h|T}$$

▶ Under weak exogeneity, with a VAR(p) we have
$$y_{T+h|T} = \Pi + \Phi_1 y_{T+h-1|T} + ... + \Phi_p y_{T+h-p|T}$$

This can be computed recursively, imposing $y_{T-s|T} = y_{T-s}$ for $s > 0$.

▶ With a VAR(1) we have explicit formulas
$$y_{T+1|T} = \Pi + \Phi_1 y_T$$
$$y_{T+2|T} = \Pi + \Phi_1 y_{T+1|T} = (I + \Phi_1)\Pi + (\Phi_1)^2 y_T$$
$$y_{T+3|T} = [I + \Phi_1 + (\Phi_1)^2]\Pi + (\Phi_1)^3 y_T$$
$$y_{T+h|T} = \left[\sum_{i=0}^{h-1} (\Phi_1)^i\right] \Pi + (\Phi_1)^h y_T$$

---

## Forecast

▶ We can also compute the forecast error
$$e_{T+h|T} \equiv y_{T+h} - y_{T+h|T}$$

▶ Using the VMA($\infty$) representation, this is
$$e_{T+h|T} = e_{T+h} + \Theta_1 e_{T+h-1} + ... + \Theta_{h-1} e_{T+1}$$

In a VAR(1): $e_{T+h|T} = e_{T+h} + (\Phi_1)^1 e_{T+h-1} + ... + (\Phi_1)^{h-1} e_{T+1}$.

▶ We can also compute the **Mean-Squared Forecast Error (MSFE):**
$$MSFE_y(h) = V(e_{T+h|T}) = \sum_{i=0}^{h-1} \Theta_i \Sigma \Theta_i'$$

In a VAR(1): $MSFE_y(h) = \sum_{i=0}^{h-1} (\Phi_1)^i \Sigma [(\Phi_1)^i]'$

---

## Forecast

▶ If we work with the estimated VAR
$$\hat{y}_{T+h|T} = \hat{\Pi} + \hat{\Phi}_1 \hat{y}_{T+h-1|T} + ... + \hat{\Phi}_p \hat{y}_{T+h-p|T}.$$

▶ Also
$$e_{T+h|T} \equiv y_{T+h} - \hat{y}_{T+h|T} = (y_{T+h} - y_{T+h|T}) - (y_{T+h|T} - \hat{y}_{T+h|T})$$

Then
$$MSFE_{\hat{y}}(h) = MSFE_y(h) + V(y_{T+h|T} - \hat{y}_{T+h|T})$$

Shock uncertainty + Parametric Uncertainty.

## Anticipation and Granger Causality

▶ Can a variable help to forecast another?

▶ **Granger causality:** $y_2$ Granger cause $y_1$ if
$$MSFE_{y_1}(h|\mathcal{I}_t) < MSFE_{y_1}(h|\tilde{\mathcal{I}}_t),$$

where $\mathcal{I}_t$ is contains all information relevant to predict $y_1$ at $t$, while $\tilde{\mathcal{I}}_t$ contains the same except for the history of $y_2$ (i.e. $\mathcal{I}_t = \{\tilde{\mathcal{I}}_t, y_2^t\}$).

▶ In the VAR context, this can be implemented with a test that the coefficients of lags of $y_2$ in the equation for $y_1$ are **jointly equal to zero**.

▶ These tests are implemented in both ways: Does $y_2$ Granger cause $y_1$? Does $y_1$ Granger cause $y_2$?

▶ **Be careful:**
 ▶ Causality here means a very particular thing: "Anticipation".  
 ▶ This is a test about forecasts in sample.
