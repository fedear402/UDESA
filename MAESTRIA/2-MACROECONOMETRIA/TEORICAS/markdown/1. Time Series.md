## Objects of Study

▶ Variable(s) of interest: $y_t$. Information set at $t$: $I_t$ (includes $y_t, y_{t-1}, ...$)

▶ **Forecasts:**
 ▶ **Unconstrained:**
   $$E(y_{T+h}|I_{T-1}), \text{ for } h = 0, 1, ..., H.$$
 
 ▶ **Constrained:**
   $$E(y_{T+h}|I_{T-1}, x_T, x_{T+1}, ..., x_{T+J}), \text{ for } h = 0, 1, ..., H.$$
   for some variable(s) $x_t \in I_t$.

▶ **Causal Effect/Impulse Responses/Structural Analysis:**
 $$E(y_{T+h}|I_{T-1}, s_t = \bar{s}) - E(y_{T+h}|I_{T-1}), \text{ for } h = 0, 1, ..., H.$$
 for some variable(s) $s_t \in I_t$.

## Main approaches

**Two main approaches:**
1. To model the complete dynamic behavior of the relevant variables ⇒ Compute the conditional expectation of interest.
2. To model the conditional expectation of interest directly.

**Pros and Cons:**
1. **Pros:** Can do many things with one model (e.g. forecast, causal effect to different treatments, etc.). **Cons:** Requires to impose a lot of structure (assumptions), to estimate many parameters, and it might be hard to handle computationally (curse of dimensionality).

2. **Pros:** Requires fewer assumptions and parameters; easier to capture some non-linearities. **Cons:** Useful for one goal only, but not all; might hinder relevant required assumptions.

## Stationary processes

### Stationarity

▶ Consider a univariate stochastic process $\{y_t\}$.

▶ **Some definitions:**
 ▶ Unconditional Expectation: $E(y_t) = \mu_t$.
 ▶ Unconditional Variance: $V(y_t) = \gamma_{0,t}$.
 ▶ Unconditional Covariance: $Cov(y_t, y_{t-j}) = \gamma_{j,t}$.

▶ **A process is said to be (weakly) stationary if:**
 ▶ $E(y_t) = \mu < \infty$ for all $t$.
 ▶ $Cov(y_t, y_{t-j}) = \gamma_j < \infty$ for all $j, t$.

▶ Stationarity ⇒ $Cov(y_t, y_{t-j}) = Cov(y_t, y_{t+j})$, i.e. $\gamma_j = \gamma_{-j}$.

---

### Some stationary processes: WN

▶ **White Noise (WN):** a process $\epsilon_t$ follows a WN process if:
 ▶ $E(\epsilon_t) = 0$ for all $t$.
 ▶ $V(\epsilon_t) = \sigma^2 < \infty$ for all $t$.
 ▶ $Cov(\epsilon_t, \epsilon_{t-j}) = 0$, for $j > 0$ and for all $t$.

▶ If follows that a WN is stationary, with $\mu = 0$, $\gamma_0 = \sigma^2$ and $\gamma_j = 0$ for $j > 0$. We write $\epsilon_t \sim WN(0, \sigma^2)$.

▶ **A particular case:** if $\epsilon_t$ is drawn from an independent and identically distributed (i.i.d.) normal distribution; i.e. $\epsilon_t \sim N(0, \sigma^2)$ for all $t$.

---

### Some stationary processes: AR

▶ **Auto-regressive process of order 1, AR(1):**
 $$y_t = c + \phi y_{t-1} + \epsilon_t$$
 with $\epsilon_t \sim WN(0, \sigma^2)$, and $|c|, \sigma < \infty$.

▶ We will see that this process is stationary if $|\phi| < 1$.

▶ Notice that if $y_t = c + \phi y_{t-1} + \epsilon_t$ for all $t$, it also holds that $y_{t-1} = c + \phi y_{t-2} + \epsilon_{t-1}$. Thus,
 $$y_t = c + \phi c + \phi^2 y_{t-2} + \epsilon_t + \phi \epsilon_{t-1}.$$

▶ Doing this until a period $n$,
 $$y_t = c + \phi c + ... + \phi^n c + \phi^{n+1} y_{t-(n+1)} + \epsilon_t + \phi \epsilon_{t-1} + ... + \phi^n \epsilon_{t-n}$$
 $$= \mu \sum_{j=0}^n \phi^j + \phi^{n+1} y_{t-(n+1)} + \sum_{j=0}^n \phi^j \epsilon_{t-j}.$$

▶ Taking the limit with $n \to \infty$, if $|\phi| < 1$ we have
 ▶ $\lim_{n \to \infty} \sum_{j=0}^n \phi^j = \sum_{j=0}^{\infty} \phi^j = \frac{1}{1-\phi}$.
 ▶ $\lim_{n \to \infty} \phi^{n+1} y_{t-(n+1)} = 0$.
 ▶ $\lim_{n \to \infty} \sum_{j=0}^n \phi^j \epsilon_{t-j} = \sum_{j=0}^{\infty} \phi^j \epsilon_{t-j}$ is well defined (i.e. it is not $\infty$).

▶ Then, if $|\phi| < 1$,
 $$y_t = \frac{c}{1-\phi} + \sum_{j=0}^{\infty} \phi^j \epsilon_{t-j}.$$
 This is called the MA($\infty$) representation of an AR(1) process (more later).

▶ Using this, we can compute,
 - $E(y_t) = \frac{c}{1-\phi} + \sum_{j=0}^{\infty} \phi^j E(\epsilon_{t-j}) = \frac{c}{1-\phi}$.
 - $V(y_t) = E[(y_t - E(y_t))^2] = \sum_{j=0}^{\infty} (\phi^2)^j E(\epsilon_{t-j}^2) = \frac{\sigma^2}{1-\phi^2}$.
 - $Cov(y_t, y_{t-s}) = E[(y_t - E(y_t))(y_{t-s} - E(y_t))] = \phi^s \frac{\sigma^2}{1-\phi^2}$.

---

### Some stationary processes: AR & MA

▶ **Auto-regressive process of order p, AR(p):**
 $$y_t = c + \phi_1 y_{t-1} + ... + \phi_p y_{t-p} + \epsilon_t$$
 with $\epsilon_t \sim WN(0, \sigma^2)$, and $|c|, \sigma < \infty$. Conditions for stationarity are more complicated.

▶ **Moving average of order 1, MA(1):**
 $$y_t = c + \epsilon_t + \theta \epsilon_{t-1}$$
 with $\epsilon_t \sim WN(0, \sigma^2)$ for all $t$, and $|c|, |\theta|, \sigma < \infty$. Properties:
 - $E(y_t) = E(c + \epsilon_t + \theta \epsilon_{t-1}) = \mu + E(\epsilon_t) + \theta E(\epsilon_{t-1}) = c$.
 - $V(y_t) = E[(y_t - c)^2] = E[(\epsilon_t + \theta \epsilon_{t-1})^2] = E(\epsilon_t^2 + \theta^2 \epsilon_{t-1}^2 + \epsilon_t \theta \epsilon_{t-1}) = (1 + \theta^2)\sigma^2$.
 - $Cov(y_t, y_{t-1}) = E[(y_t - c)(y_{t-1} - c)] = E[(\epsilon_t + \theta \epsilon_{t-1})(\epsilon_{t-1} + \theta \epsilon_{t-2})] = \theta \sigma^2$
 - For $j > 1$, $Cov(y_t, y_{t-j}) = 0$

▶ The MA(1) process is always stationary.

---

### Some stationary processes: MA

▶ **Moving average of order q, MA(q):**
 $$y_t = c + \epsilon_t + \theta_1 \epsilon_{t-1} + ... + \theta_q \epsilon_{t-q}$$
 with $\epsilon_t \sim WN(0, \sigma^2)$ for all $t$, and $|c|, |\theta_1|, ..., |\theta_q|, \sigma < \infty$. MA(q) is stationary if $|\theta_j| < \infty$ for $j = 1, ..., q$.

▶ **Moving average of order $\infty$, MA($\infty$):**
 $$y_t = c + \sum_{j=0}^{\infty} \theta_j \epsilon_{t-j}$$
 with $\epsilon_t \sim WN(0, \sigma^2)$ for all $t$ and $\theta_0 = 1$.

▶ It can be shown that MA($\infty$) is stationary if $\sum_{j=0}^{\infty} |\theta_j| < \infty$.

---

### Some stationary processes: ARMA & Wold Representation Theorem

▶ **Generalization: ARMA(p,q):**
 $$y_t = c + \phi_1 y_{t-1} + ... + \phi_p y_{t-p} + \epsilon_t + \theta_1 \epsilon_{t-1} + ... + \theta_q \epsilon_{t-q}$$
 with $\epsilon_t \sim WN(0, \sigma^2)$.

▶ It can be shown that the process is stationary as long as the AR part is.

▶ **Wold Representation Theorem:** Every stationary process has a MA($\infty$) representation.

▶ In particular, every stationary ARMA(p, q) process has a MA($\infty$) representation.

▶ This implies that, although we may not know the true data generating process, if the series is stationary it has a MA($\infty$) representation. Then, as ARMA models also have a MA($\infty$) representation, we can try to approximate the true MA($\infty$) process (that cannot be estimated because it has $\infty$ parameters) with an ARMA process that can be estimated.

---

### Simplifying the notation: Lag operator

▶ **The lag operator, L, applied to a process $\{y_t\}$:**
 ▶ $Ly_t \equiv y_{t-1}$
 ▶ $L^2 y_t \equiv L(Ly_t) = L(y_{t-1}) = y_{t-2}$ ...
 ▶ $L^k y_t = y_{t-k}$

▶ **Properties:**
 ▶ $L(\alpha x_t) = \alpha L x_t$
 ▶ $L(x_t + y_t) = L x_t + L y_t$

▶ **Polynomial on the lag operator:** $\alpha_k(L) \equiv \alpha_0 + \alpha_1 L + \alpha_2 L^2 + ... + \alpha_k L^k$.

▶ **Then:** $\alpha_k(L)y_t = \alpha_0 y_t + \alpha_1 y_{t-1} + \alpha_2 y_{t-2} + ... + \alpha_k y_{t-k}$.

▶ **Consider an ARMA(p, q) process:**
 $$y_t = \phi_1 y_{t-1} + ... + \phi_p y_{t-p} + \epsilon_t + \theta_1 \epsilon_{t-1} + ... + \theta_q \epsilon_{t-q}$$

▶ **Using L we can write:**
 $$(1 - \phi_1 L - ... - \phi_p L^p)y_t = (1 + \theta_1 L + ... + \theta_q L^q)\epsilon_t$$
 or,
 $$\Phi_p(L)y_t = \Theta_q(L)\epsilon_t$$
 where $\Phi_p(L) \equiv 1 - \phi_1 L - ... - \phi_p L^p$ and $\Theta_q(L) \equiv 1 + \theta_1 L + ... + \theta_q L^q$.

## Regressions with stationary variables

▶ **Simple linear model:**
 $$y_t = \beta z_t + u_t$$
 $z_t$ might be a vector. Assume $y_t, z_t, u_t$ are stationary.

▶ **Key linear-model assumption: exogeneity. Alternatives:**
 ▶ Contemporaneous: $E(u_t|z_t) = 0$.
 ▶ Weak: $E(u_t|z_t, z_{t-1}, z_{t-2}, ...) = 0$.
 ▶ Strong: $E(u_t|..., z_{t+2}, z_{t+1}, z_t, z_{t-1}, z_{t-2}, ...) = 0$.

▶ $\beta$ can be consistently estimated by OLS under any of these three (consistency is more complicated in time series, more later).

▶ Whether we can justify that one of these holds depends on the specific application.

▶ **Distributed lag (DL) model:**
 $$y_t = \alpha + \beta_0 x_t + \beta_1 x_{t-1} + ... + \beta_q x_{t-q} + u_t.$$
 Consistency requires either weak of strong exogeneity of $x_t$.
 Notice we can write this model as in the specification with $z_t$ above.

▶ The asymptotic variance of OLS hinges on the second moments of $u_t$.

▶ **Recall the classical (Gauss-Markov) assumptions:**
 ▶ Homoskedasticity: $Var(u_t) = \sigma^2$ for all $t$.
 ▶ No serial correlation: $Cov(u_t, u_\tau) = 0$ for $t \neq \tau$.

▶ Persistence in time series presents a challenge for the second assumption. If residuals present serial correlation, OLS variance will be biases, leading to over-rejection of the null hypothesis (e.g. in the test for $H_0: \beta = 0$ using the t-stat $\hat{\beta}/\sqrt{\widehat{Var}(\hat{\beta})}$, if $Var(\hat{\beta})$ is artificially large the t-stat is small, leading to acceptance even in the null is false).

▶ Consistency is not dependent on these assumptions.

▶ To fix this problem, the HAC or Newey-West variance estimator, which controls for the possibility of autocorrelation and heteroskedasticity in th residual.

▶ **Generalization: ADL model**
 $$y_t = \alpha + \gamma_1 y_{t-1} + \gamma_2 y_{t-2} + ... + \gamma_p y_{t-p} + \beta_0 x_t + \beta_1 x_{t-1} + ... + \beta_q x_{t-q} + u_t.$$

▶ Richer dynamics than DL model.

▶ Auto-correlation in $u_t$ might cause consistency problems (choosing $p$ is quite relevant).

## Unit Roots and Co-integration

▶ **Recall: A process is stationary if**
 ▶ $E(y_t) = \mu < \infty$ for all $t$.
 ▶ $Cov(y_t, y_{t-j}) = \gamma_j < \infty$ for all $j, t$.

 Then, $y_t$ is non-stationary if at least one of them doesn't hold.

▶ Different non-stationary processes differ depending on the source of non-stationarity (e.g. mean, variance, etc.). We describe 3 types:
 ▶ Deterministic trend.
 ▶ Random walk.
 ▶ Random walk with drift.

▶ **Deterministic trend (DT):** $y_t = d_t + \epsilon_t$,
 where $d_t$ is a known function of time (e.g. $d_t = \alpha + \beta t$) and $\epsilon_t \sim WN(0, \sigma^2)$. Thus,
 ▶ $E(y_t) = d_t$.
 ▶ $V(y_t) = V(\epsilon_t) = \sigma^2$.

 The source of non-stationary is the mean.

▶ **Random Walk (RW):** $y_t = y_{t-1} + \epsilon_t$, where $\epsilon_t \sim WN(0, \sigma^2)$.
 We can iterate backwards to obtain,
 $$y_t = y_{t-1} + \epsilon_t = y_{t-2} + \epsilon_{t-1} + \epsilon_t = ... = y_0 + \sum_{j=1}^t \epsilon_j$$
 Then
 ▶ $E(y_t) = y_0$.
 ▶ $V(y_t) = tV(\epsilon_t) = t\sigma^2$.

 The source of non-stationary is the variance.

▶ **Random Walk with drift (RWD):** $y_t = \alpha + y_{t-1} + \epsilon_t$, where $\epsilon_t \sim WN(0, \sigma^2)$. Iterating backwards,
 $$y_t = \alpha + y_{t-1} + \epsilon_t = \alpha + \alpha + y_{t-2} + \epsilon_{t-1} + \epsilon_t = ... = \alpha t + y_0 + \sum_{j=1}^t \epsilon_j$$
 Then
 ▶ $E(y_t) = y_0 + \alpha t$.
 ▶ $V(y_t) = tV(\epsilon_t) = t\sigma^2$.

 The sources of non-stationary are both the mean and the variance. A RWD is a linear DT plus a RW.

▶ **Generalization:** Replacing $\epsilon_t \sim WN(0, \sigma^2)$ with $u_t$ being stationary with mean zero.

▶ **Unit root test:** In the following regression
 $$y_t = \alpha + \beta t + \phi y_{t-1} + u_t,$$
 test
 $$H_0: \phi = 1 \text{ vs. } H_A: |\phi| < 1$$
 The t-stat has a non-standard distribution. DF, ADF, DF-GLS,...

▶ **Order of integration:** $y_t$ is I(d) if $y_t - y_{t-d}$ is stationary.

▶ **Co-integration:** two I(d) series $y_t, x_t$ are co-integrated if there is a linear combination between them that is I(0).

▶ **Interpretation:** Common stochastic trend (co-integration $\nRightarrow$ Causality).

▶ Regressions in levels with non-stationary variables make sense only if they are co-integrated. The problem is not consistency, is the variance.

▶ **Simple co-integration test (Engle-Granger):** Run a regression in levels, perform a unit root test on the residuals.

▶ We will discuss more about co-integration in the context of vectors of variables (VEC)

## Comments about Asymptotics in Time Series

▶ In Advanced Econometrics you studied extensively the asymptotic properties of OLS, IV, ML. Main results: LLN, CLT, Delta Method.

▶ **Key assumption in cross-section:** i.i.d. samples.

▶ This doesn't hold in time series. A complete treatment is beyond the scope of this course (if interested, see Hamilton, 1994, Ch. 7, 16, 17).

▶ **Some comments:**
 ▶ **Weak-stationarity:** most of the results carry through. Long-run variance is more complicated (recall HAC).
 ▶ **Unit-roots:** super-consistency, asymptotic distribution is not normal (DF), local to unity.
