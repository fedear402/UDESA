## Impulse Responses

**Impulse response:**
$$IRF_{x,s}(h) \equiv E(x_{T+h}|\mathcal{I}_{T-1}, s_T = \bar{s}) - E(x_{T+h}|\mathcal{I}_{T-1}), \text{ for } h = 0, 1, ..., H$$

for some variable $s_t \in \mathcal{I}_t$. In the VAR context, suppose $x_t, s_t$ are in the vector $y_t$. Also $\mathcal{I}_{t-1} = \{y_{t-1}, y_{t-2}, ...\}$

**Simple VAR(1):** $y_t = \Phi_1 y_{t-1} + e_t$, with $E(e_t) = 0$ and $V(e_t) = \Sigma$.

**Solving backwards from $T + h$ to $T$:** 
$$y_{T+h} = (\Phi_1)^h y_T + \sum_{j=0}^{h-1} (\Phi_1)^j e_{T+h-j}$$

Then,
$$E(y_{T+h}|\mathcal{I}_{T-1}) = (\Phi_1)^h y_{T|T-1}$$
$$E(y_{T+h}|\mathcal{I}_{T-1}, s_T = \bar{s}) = (\Phi_1)^h y_{T|T-1,s}$$

where $y_{T|T-1} \equiv E(y_T|\mathcal{I}_{T-1})$ and $y_{T|T-1,s} \equiv E(y_T|\mathcal{I}_{T-1}, s_T = \bar{s})$.

Recall: $(\Phi_1)^h = \Theta_h$ is the VMA($\infty$) representation of the VAR(1).

Thus,
$$IRF_{y,s}(h) = (\Phi_1)^h (y_{T|T-1,s} - y_{T|T-1}) = (\Phi_1)^h e_{T|s}$$

where $e_{T|s} \equiv E(e_T|s_T = \bar{s})$:
- It is independent from $T-1$ due to linearity and i.i.d. shocks
- It is not equal to zero because we know that $s$ element of $e_{T|s}$ is $e^s_{T|s} = \bar{s} - s_{T|T-1} = \tilde{s}$ (the "surprise" in $s_T$)
- The other elements are not necessarily zero as $V(e_t) = \Sigma$ is not diagonal

**Useful result:** without loss of generality, assume the shock of interest is ordered first; i.e. $e_t = [e^s_t, (e^{ns}_t)']'$, where $e^{ns}_t$ are all members in $e_t$ that are not $e^s_t$, with

$$E(e_t) = 0, \text{ and } V(e_t) = \Sigma = V\begin{bmatrix} e^s_t \\ e^{ns}_t \end{bmatrix} = \begin{bmatrix} \Sigma_{s,s} & \Sigma_{s,ns} \\ \Sigma_{ns,s} & \Sigma_{ns,ns} \end{bmatrix}$$

Then, $E(e^{ns}_t|e^s_t = \tilde{s}) = \Sigma_{s,ns}(\Sigma_{s,s})^{-1}\tilde{s}$.

With this result, $e_{T|s} = [1, (\Sigma_{s,ns}(\Sigma_{s,s})^{-1})']'\tilde{s} \equiv B_s \tilde{s}$, and

$$IRF_{y,s}(h) = (\Phi_1)^h B_s \tilde{s}$$

More generally, using the VMA($\infty$) representation (with a generic deterministic component $\mu_t$),

$$y_{t+h} = \mu_{t+h} + \sum_{j=0}^{\infty} \Theta_j e_{t+h-j}$$

Then 
$$E(y_{T+h}|\mathcal{I}_{T-1}) = \mu_{T+h} + \sum_{j=h+1}^{\infty} \Theta_j e_{T+h-j}$$

$$E(y_{T+h}|\mathcal{I}_{T-1}, s_t = \bar{s}) = \mu_{T+h} + \sum_{j=h+1}^{\infty} \Theta_j e_{T+h-j} + \Theta_h e_{T|s}$$

Thus,
$$IRF_{y,s}(h) = \Theta_h e_{T|s} = \Theta_h B_s \tilde{s}$$

$IRF_{y,s}(h) = \Theta_h B_s \tilde{s}$ has three parts:
- The impulse/surprise/news/shock ($\tilde{s}$)
- How $\tilde{s}$ affects all innovations at the moment of the impulse ($B_s$)
- How the impulse propagates through time ($\Theta_h$, the MA($\infty$) representation)

### Some comments:
- The IRF to a given value for $s_T$ is equal to the effect that the shock/news/surprise to $s_T$ has on other variables, relative to past info in the model
- Given linearity, the IRF is just scaled by the size of the shock; so generally we use a normalization (e.g. unit shock, one-stdev shock, etc)
- This also implies that IRFs from VARs are symmetric
- The IRF is independent from the starting point $\mathcal{I}_{T-1}$ and deterministic components. This is also due to linearity
- Generally, we plot $IRF_{x,s}(h)$ as a function of $h$, for each $x$ of interest

## Identification Problem

**Relevant question:** can we give the IRF a causal interpretation?

This depends on the definition of "causal."
- If by causality we mean the information that $s_T = \bar{s}$ adds relative to $\mathcal{I}_{T-1}$ (i.e. relative to $s_{T|T-1}$), then it is "causal"
- But in economics "causal" generally means the effect of a variable on others, **maintaining everything else equal** (ceteris paribus)
- As in general the matrix $V(e_t) = \Sigma$ is not diagonal, news about $s_T$ implicitly contain news about other variables as well (i.e. $B_s$ is just a correlation among shocks, no sense of causality)
- In other words, we cannot be sure that the news $e_{s,T}$ was generated by an "autonomous" movement in $s$ or due to another source
- Thus, the IRF we have described so far does not isolate the effect of news about variable $s$ maintaining everything else equal, so this type of causal effect is not identified with the assumptions we used so far. We will need extra assumptions, not coming from the data (similar to what a good instrument is)

### Another view of the identification problem:

Consider a new set of shocks $u_t$, created by linear combinations of $e_t$,
$$u_t = Q e_t$$

where $Q$ is a $m \times m$ **invertible** matrix (a.k.a. rotation matrix).

Given this, we can write the VMA($\infty$) representation as
$$y_t = \Theta(L)e_t = \Theta(L)Q^{-1} Q e_t = \Psi(L)u_t$$

where $\Psi(L) \equiv \Theta(L)Q^{-1}$ and $u_t \equiv Q e_t$.

Both $\Theta(L)$ and $\Psi(L)$ are valid VMA($\infty$) representations for $y_t$, but they generate different causal interpretations.

The problem is that $\Theta(L)$ and $\Psi(L)$ are **observationally equivalent**, because the data is only informative about $\Phi, \Sigma$ (and thus $\Theta(L)$) but it is silent about $Q$.

As the equivalence is valid for any $Q$ that is invertible, there are infinite VMA($\infty$) representations (and IRFs) that are valid, and thus infinite alternative causal interpretations. In other words, $Q$ is not identified.

To give a causal interpretation we need to choose a particular $Q$. We will select the one we find "more interesting" (more details later).

There is no general solution, it depends on the problem we are analyzing.

## Structural VAR

**Yet another related view: Structural VAR (SVAR)**

$$A_0 y_t = \Lambda + A_1 y_{t-1} + ... + A_p y_{t-p} + u_t$$

$u_t$ are "structural shocks": i.i.d., mean zero and diagonal $E(u_t u_t') = \Omega$.

This is called **Structural** because it imposes contemporaneous relationships between variables (given by $A_0$), while the reduced-form VAR doesn't. Also, because structural shocks are orthogonal ($\Omega$ is diagonal).

Of course, there is a relationship between VAR and SVAR:
$$\Phi_j = A_0^{-1} A_j, \quad \Pi = A_0^{-1} \Lambda \quad \text{and} \quad e_t = A_0^{-1} u_t$$

so we can also write
$$y_t = \Pi + \Phi_1 y_{t-1} + ... + \Phi_p y_{t-p} + A_0^{-1} u_t$$

Given our previous discussion about $Q$, we have $Q = A_0$. Thus, as $Q$ was not identified, neither will $A_0$ without additional restrictions.

To see why we cannot estimate $A_0$, let's consider a two-variable SVAR model:
$$[A_0]_{\{1,1\}} y_{1,t} + [A_0]_{\{1,2\}} y_{2,t} = [A_1]_{\{1,1\}} y_{1,t-1} + [A_1]_{\{1,2\}} y_{2,t-1} + u_{1,t}$$
$$[A_0]_{\{2,1\}} y_{1,t} + [A_0]_{\{2,2\}} y_{2,t} = [A_1]_{\{1,1\}} y_{1,t-1} + [A_1]_{\{1,2\}} y_{2,t-1} + u_{2,t}$$

We had argued that a reduced-form VAR could be estimated using OLS under the weak exogeneity assumption $E(u_t|y_{t-1}, y_{t-2}, ...) = 0$. Clearly, this assumption does not apply to estimate the SVAR because the contemporaneous values of $y_t$ are on both the left-hand and right-hand sides of the equations. Therefore, we would need to assume $E(u_t|y_t, y_{t-1}, y_{t-2}, ...) = 0$, which trivially does not hold.

So, in order to provide a causal interpretation, we must choose the matrix $A_0$ we want to use or impose restrictions on the model to find the elements of $A_0$.

### Full identification: 
$A_0$ has $m^2$ elements, then we need $m^2$ restrictions.
- **Independence of shocks:** $\Omega$ is diagonal. These are $\frac{m(m-1)}{2}$ restrictions.
- **Normalization:** Either the elements in the diagonal of $A_0$ are equal to one, or $\Omega = I$ (we cannot separately identify them). This gives $m$ restrictions.
- We still need $m^2 - \frac{m(m-1)}{2} - m = \frac{m(m-1)}{2}$ additional restrictions to identify all the columns of $A_0$ (i.e. to identify the effect of all the structural shocks).

### Partial Identification: 
We may not care about all the shocks, so it is enough to compute the columns of $A_0^{-1}$ corresponding to the desired shocks. This requires less restrictions ($m \times \#s$).

In the end, the identification process is a function:
$$\hat{\Pi}, \hat{\Phi}_j, \hat{\Sigma} + \text{Identification Assumptions} \rightarrow \text{Columns of } A_0^{-1} \text{ of interest}$$

### Where do identification restrictions come from?
- A theoretical model
- Lags on the availability of information
- Physical restrictions
- Institutional characteristics
- Market structure

This is not an easy task!

### Frequent strategies to impose restrictions:
- Short-run restrictions (recursive and non-recursive)
- Long-run restrictions
- Sign restrictions
- Others

## Inference for IRFs

We have already saw how to compute the IRF for a reduced-form VAR. For SVAR, we just need to remember that $e_t = A_0 u_t$. Then,

$$y_t = \sum_{j=0}^{\infty} \Theta_j e_{t-j} = \sum_{j=0}^{\infty} \Theta_j A_0^{-1} A_0 e_{t-j} = \sum_{j=0}^{\infty} \Psi_j u_{t-j}$$

where $\Psi_j = \Theta_j A_0^{-1}$.

**Inference:** Notice that $\Psi_j$ is a non-linear function of the parameters. We will explore three alternatives:
- Asymptotic distribution
- Monte-Carlo
- Bootstrap

### Asymptotic distribution: 
Let $\beta$ be a column vector containing all the parameters of the SVAR. Under stationarity we have,
$$\sqrt{T}(\hat{\beta} - \beta) \xrightarrow{d} N(0, V(\beta))$$

Using asymptotic theory (Delta Method), and defining $\psi_j(\beta) \equiv \text{vec}(\Psi_j(\beta))$ we can obtain,
$$\sqrt{T}[\psi_j(\hat{\beta}) - \psi_j(\beta)] \xrightarrow{d} N(0, [\nabla_{\beta}\psi_j(\beta)]V(\beta)[\nabla_{\beta}\psi_j(\beta)]')$$

where $\nabla_{\beta}\psi_j(\beta)$ is the gradient of $\psi_j(\beta)$. See Hamilton (1994), Ch. 11.7.

The problem with this approach is that asymptotic approximations are generally inaccurate for short samples, particularly because the function $\psi_j(\beta)$ is highly non-linear.

### Montecarlo: Inference by simulation.

1. Estimate the model: $\hat{\Pi}, \hat{\Phi}_j, \hat{\Sigma}$. Compute $\hat{A}_0$ and IRFs $\hat{\Psi}_j$.
2. Choose a large number $K$. For $k = 1, ..., K$
   - 2.1 Assuming normality of the error $e_t$, generate a random sequence $e_t^{(k)}$ for $t = 1, .., T$ using a random number generator for a multivariate normal with mean zero and variance $\hat{\Sigma}$.
   - 2.2 Using the generated errors and the estimated parameters, construct a series $y_t^{(k)}$ for $t = 1, .., T$ (e.g. for a VAR(1) with no constants, $y_t^{(k)} = \hat{\Phi}_1 y_{t-1}^{(k)} + e_t^{(k)}$, with $y_0^{(k)} = y_0$).
   - 2.3 With this new dataset, estimate the parameters again $\hat{\Phi}_j^{(k)}, \hat{\Sigma}^{(k)}$. Compute $\hat{A}_0^{(k)}$ and the impulse responses $\hat{\Psi}_j^{(k)}$.
3. Use $\hat{\Psi}_j^{(k)}$ for $k = 1, ..., K$ for inference (e.g. sort them and find percentiles 2.5 and 97.5, plot a histogram, compute p-values, etc.)

Usually, $K \approx 1000$ is enough (try several and see if results are the same).
Can be used for testing about any non-linear functions of the parameters.
**Drawback:** it assumes errors are normal.

### Bootstrap: Inference by re-sampling. 

Same algorithm, except for:
- In step 1, compute also $\hat{e}_t$ using the estimated parameters.
- Replace step 2.1 by: Draw with replacement from the estimated errors $\hat{e}_t$ a sequence $e_t^{(k)}$ for $t = 1, .., T$.

**Difference with Montecarlo:** doesn't assume normality of $e_t$ (non-parametric procedure). In particular, it can give bands that are not symmetric.

In practice, many times they yield similar results.

This procedure assumes errors are i.i.d. If we suspect errors are autocorrelated and/or heteroskedastic, we can apply **block bootstrap**:
- Instead of drawing individual errors $\hat{e}_t$, draw blocks of errors (consecutive observations):
  - Blocks of fixed size,
  - Blocks of random size, with a given average size,
- See K-L Ch. 12., or Politis & Romano (1994, JASA) for more details.

# Identification by Short-Run restrictions

### Recursive

A first approach to identify $A_0$ is to impose restrictions directly on it.

Given that $A_0$ describes the contemporaneous (or short-run) relationships between variables, this approach is known as **short-run restrictions**.

Two alternatives: **Recursive** and **Non-recursive**.

**Recursive identification:** Assume that $A_0$ is lower triangular.

If $A_0$ is lower triangular, so is $A_0^{-1}$. Then, given $e_t = A_0^{-1} u_t$ we have

$$\begin{bmatrix} e_{1,t} \\ e_{2,t} \\ \vdots \\ e_{k,t} \end{bmatrix} = \begin{bmatrix} a_{11} & 0 & \cdots & 0 \\ a_{21} & a_{22} & \cdots & 0 \\ \vdots & \vdots & \ddots & \vdots \\ a_{k1} & a_{k2} & \cdots & a_{kk} \end{bmatrix} \begin{bmatrix} u_{1,t} \\ u_{2,t} \\ \vdots \\ u_{k,t} \end{bmatrix}$$

where $a_{i,j}$ is the characteristic element of $A_0^{-1}$.

Notice: we impose $\frac{m(m-1)}{2}$ restrictions, as required for full identification.

### What is the assumption here? 

That there is a contemporaneous causal order between variables: the first is not affected by any other variable contemporaneously, the second is just affected by the first contemporaneously, and so on. Thus, the order of variables is relevant in this case.

Note: most DSGE model don't imply this type of order for all variables.

### How to compute the unrestricted elements of $A_0^{-1}$? 

From $e_t = A_0^{-1} u_t$,

$$\Sigma = E(e_t e_t') = E[(A_0^{-1} u_t)(A_0^{-1} u_t)'] = E[A_0^{-1} u_t u_t' (A_0^{-1})']$$
$$= A_0^{-1} E(u_t u_t')(A_0^{-1})' = A_0^{-1} \Omega (A_0^{-1})' = A_0^{-1} \Omega^{1/2} \Omega^{1/2} (A_0^{-1})'$$

(Abuse of notation: $\Omega^{1/2}$ is a diagonal matrix with $j,j$ element equal $\Omega_{jj}^{1/2}$)

**Cholesky Decomposition:** A positive semi-definite matrix can be decomposed by a lower-triangular matrix $P$ that satisfies $\Sigma = P P'$.

Thus, $P = A_0^{-1} \Omega^{1/2}$. Recall that the diagonal elements of $A_0$ and $\Omega$ cannot be separately identified.

### Some warm-up examples:

#### Persistent and transitory income shocks: 
According to the permanent income hypothesis, if the income shock is short lived, consumption will not move significantly, while if the shock is persistent consumption will indeed change. Output, on the other hand, should move with both shocks.

If $y_t = [\Delta c_t, \Delta gdp_t]'$, if $A_0$ is lower triangular the first structural shock will have a contemporaneous effect on both variables, but the second shock will just affect the second variable contemporaneously. Thus,

$$\begin{bmatrix} e_t^c \\ e_t^{gdp} \end{bmatrix} = \begin{bmatrix} a_{11} & 0 \\ a_{21} & a_{22} \end{bmatrix} \begin{bmatrix} u_t^{persistent} \\ u_t^{transitory} \end{bmatrix}$$

#### Foreign interest rate shocks: 
If $y_t = [r_t^*, \Delta gdp_t]'$, $A_0$ being lower triangular is consistent with the small and open economy assumption. Thus,

$$\begin{bmatrix} e_t^{r^*} \\ e_t^{gdp} \end{bmatrix} = \begin{bmatrix} a_{11} & 0 \\ a_{21} & a_{22} \end{bmatrix} \begin{bmatrix} u_t^{r^*} \\ u_t^{others} \end{bmatrix}$$

Notice that in the previous example we are just "naming" one shock but not the other.

When the model has more than two variables we can distinguish between **total** and **partial identification**, i.e. whether our restrictions allow us to identify all the shocks or just a few of them.

### Why we would do a partial identification?
- If we are just interested in some shocks and not in others.
- If we do not have good arguments to impose restrictions to identify all the shocks.

This distinction is not just for short-run recursive assumptions, as we already discussed.

#### Example partial identification: Monetary VAR for the USA (Stock y Watson, 2001)
$Y_t = [ur_t, \pi_t, i_t]'$, $A_0$ is lower triangular.

$$\begin{bmatrix} e_t^{ur} \\ e_t^{\pi} \\ e_t^{i} \end{bmatrix} = \begin{bmatrix} a_{11} & 0 & 0 \\ a_{21} & a_{22} & 0 \\ a_{31} & a_{32} & a_{33} \end{bmatrix} \begin{bmatrix} u_t^{others1} \\ u_t^{others2} \\ u_t^{mon} \end{bmatrix}$$

The assumption is that monetary policy shocks have a delayed effect (not contemporaneous) of $ur_t, \pi_t$, but at the same time monetary policy is decided by looking at $ur_t, \pi_t$.

But this assumption is related only to the last column in $A_0$. Why do we impose lower-triangularity?

If we are just interested in identifying the monetary policy shock and not the others, any additional restriction will no change the inference about the shock that we want to identify. In other words,

$$\begin{bmatrix} a_{11} & 0 & 0 \\ a_{21} & a_{22} & 0 \\ a_{31} & a_{32} & a_{33} \end{bmatrix} \text{ or } \begin{bmatrix} a_{11} & a_{12} & 0 \\ a_{21} & a_{22} & 0 \\ a_{31} & a_{32} & a_{33} \end{bmatrix}$$

generate the same response to a monetary policy shock (see Christiano, Eichenbaum and Evans, 1999, for a proof).

But doing the Cholesky decomposition is much easier.

So, does the order matters to identify $u_t^{mon}$?
- The order between $ur_t$ and $\pi_t$ doesn't matter.
- But it matters that $i_t$ is below $ur_t$ and $\pi_t$, as it represents the "theory" we are using.

#### Government expenditures shocks

**Question:** What is the effect of an increase in government expenditures?

Blanchard and Perotti (2002) propose the following identification: As government expenditures are decided on an annual basis (due to the budgetary process), with quarterly data this means that macroeconomic variables cannot influence government expenditures contemporaneously.

In terms of the VAR, that is equivalent to order government expenditures first in the structural VAR and apply the Cholesky decomposition.

This is another example of partial identification.

#### Identifying external shocks

We already mentioned that when we want to identify the effect of external variables in domestic variables of a small open economy, we can place the foreign variable first in the vector $y_t$ and use a Cholesky decomposition.

However, the small-economy assumption is more than just assuming contemporaneously domestic variables will not affect foreign ones. This should be the case also with the lags.

To account for this, if we order first the foreign variables, we can assume that they are **block exogenous**, i.e.

$$\Phi_j = \begin{bmatrix} \Phi_{j,1,1} & 0 \\ \Phi_{j,1,2} & \Phi_{j,2,2} \end{bmatrix}$$

for $j = 1, ..., p$.

Consistent estimates of these constrained matrices in the reduced form model can be obtained by ML, FGLS, or even OLS equation-by-equation imposing the constraints.

These different estimators are all consistent but they differ in terms of asymptotic efficiency. But if we are going to perform inference by Montecarlo or Bootstrap, consistency is all we care about.

Notice that these constraints by themselves cannot be used to identify the elements of $A_0$. But they can be used as over-identifying assumptions, which may help to reduce confidence bands.

#### The role of external factors in Latin America

Izquierdo, Romero and Talvi (2008) propose to study a VEC model

$$\Delta y_t = \Pi + \alpha \beta' y_{t-1} + \Gamma_1 \Delta y_{t-1} + ... + \Gamma_{p-1} \Delta y_{t-p+1} + e_t$$

where $y_t$ contains:
- an index of average industrial production in G7 countries (IP_X),
- an index of regional terms of trade (TOT_LAT),
- the spread on high yield bonds over US T-bonds (RISK),
- the return on 10-year US T-bonds (FINANCE_X),
- and an index of LAC7 GDP (GDP_LAT).

They use a VEC model because they find that all variables have a unit root, and one cointegration relationship.

They impose the following restrictions:
- $A_0$ is lower triangular. Besides the small assumption, this implies a causal ordering for foreign variables.
- $\Gamma_j$'s are block exogenous.
- Only domestic variables adjust to deviations from long-run relationships: $\alpha = [0 \, 0 \, 0 \, 0 \, \alpha_5]'$.

#### Exchange rate pass-through in Argentina

Consider a VAR with $y_t = \{\Delta S_t, \Delta P_t, \Delta W_t, \Delta P Reg_t\}$ (variables in logs). $S$ is the NER.

**Assumption:** Cholesky decomposition, focus on shock to $S$.

**Interpretation:** Surprises in $S$, conditional on past information included in the model. Does the order of variables matter? Only that $S$ goes first.

**Pass-Through coefficient:**
$$ERPT_X(h) = \frac{E_{t-1}(X_{t+h} - X_{t-1}|S_t) - E_{t-1}(X_{t+h} - X_{t-1})}{E_{t-1}(S_{t+h} - S_{t-1}|S_t) - E_{t-1}(S_{t+h} - S_{t-1})} = \frac{CumIRF_{\Delta X,S}(h)}{CumIRF_{\Delta S,S}(h)}$$

Notice: its is a counterfactual exercise, different from comparing the path of prices after a given depreciation.

We will call this **unconditional** or **average** ERPT.

### Non-Recursive

We may not have arguments to impose a causal order, but we may have other assumptions about the contemporaneous relationships.

We need to impose $\frac{m(m-1)}{2}$ restrictions on $A_0$. Using $\Sigma = A_0^{-1} \Omega (A_0^{-1})'$, the non-restricted elements of $A_0$ and $\Omega$ can be solved for (a system of non-linear equations).

In general, no algebraic solution. We need a numerical optimization routine.

See KL, Ch. 9 for alternatives. Also, Rubio-Ramírez et al (2010).

#### Warm-up example

The market of an agricultural product: $y_t = [p_t, q_t, w_t]'$ (price, quantity, weather). We need $\frac{3 \times 2}{2} = 3$ restrictions. Assumptions:
- Weather is exogenous.
- Weather affects supply but not demand.

The SVAR is:
$$\begin{bmatrix} 1 & a_{12} & 0 \\ a_{21} & 1 & a_{23} \\ 0 & 0 & 1 \end{bmatrix} \begin{bmatrix} p_t \\ q_t \\ w_t \end{bmatrix} = ... + \begin{bmatrix} u_t^{demand} \\ u_t^{supply} \\ u_t^{weather} \end{bmatrix}$$

Notice the similarity with IV. In general, imposing short-run zero restrictions (also with long-run assumptions) can be set up as an IV problem.

#### Application: Monetary Policy shocks in closed economy.

Kim (1999): $y_t = [i_t, M2_t, P_t, IP_t, P^{Com}_t]$. Restrictions needed for full identification: $\frac{5 \times 4}{2} = 10$.

Assumptions:
- **Monetary reaction function:** $i_t = c + \alpha_1 M2_t + \alpha_2 P^{Com}_t + f(y_{t-1}) + u_t^{ms}$. Restrictions: 2.
- **Money demand:** $M2_t = c + \beta_1 P_t + \beta_2 IP_t + \beta_3 i_t + g(y_{t-1}) + u_t^{md}$. Restrictions: 1(+2=3).
- **Price stickiness/adjustment cost:** $P_t, IP_t$ do not contemporaneously react to monetary and financial variables $(i_t, M2_t, P^{Com}_t)$. Restrictions: 6(+3=9).

With these assumptions, the SVAR is:

$$\begin{bmatrix} 1 & 0 & a_{13} & 0 & a_{15} \\ a_{21} & 1 & a_{23} & a_{24} & 0 \\ 0 & 0 & 1 & a_{34} & 0 \\ 0 & 0 & a_{43} & 1 & 0 \\ a_{51} & a_{52} & a_{53} & a_{54} & 1 \end{bmatrix} \begin{bmatrix} i_t \\ M2_t \\ P_t \\ IP_t \\ P^{Com}_t \end{bmatrix} = ... + \begin{bmatrix} u_t^{ms} \\ u_t^{md} \\ u_t^P \\ u_t^{IP} \\ u_t^{P^{Com}} \end{bmatrix}$$

To reach 10 constraints, we further impose $a_{43} = 0$. But, as me don't want to identify $u_t^P, u_t^{IP}$ this is not an issue (partial identification).

The ordering of the block $\begin{bmatrix} 1 & a_{34} \\ a_{43} & 1 \end{bmatrix}$ is irrelevant for the identification of the shocks $u_t^{ms}, u_t^{md}$.

#### Application: Fiscal Shocks

Blanchard and Perotti also present an assumption to identify tax shocks also. Let $y_t = [\tau_t, g_t, gdp_t]$ (all are real per capita, in logs).

**Assumptions:**
- With quarterly data GDP cannot influence government expenditures contemporaneously (as before).
- The within-the-quarter elasticity of taxes to GDP is estimated (outside the VAR) to be 1.85, using data on different tax types.

The SVAR is:
$$\begin{bmatrix} 1 & a_{12} & 1.85 \\ a_{21} & 1 & 0 \\ a_{31} & a_{32} & 1 \end{bmatrix} \begin{bmatrix} \tau_t \\ g_t \\ gdp_t \end{bmatrix} = ... + \begin{bmatrix} u_t^{\tau} \\ u_t^{g} \\ u_t^{other} \end{bmatrix}$$

They do not have a good assumption on $a_{12}$ and $a_{21}$, so they estimate two versions: either $a_{12} = 0$ or $a_{21} = 0$.

# Identification by Long-Run restrictions

Recall the VMA($\infty$) representation (no deterministic terms)
$$y_t = \sum_{j=0}^{\infty} \Theta_j e_{t-j} = \sum_{j=0}^{\infty} \Theta_j A_0^{-1} A_0 e_{t-j} = \sum_{j=0}^{\infty} \Psi_j u_{t-j}$$

or
$$y_t = \Theta(L)e_t = \Theta(L)A_0^{-1} A_0 e_t = \Psi(L)u_t$$

$\Theta(1) = \sum_{j=0}^{\infty} \Theta_j$ and $\Psi(1) = \sum_{j=0}^{\infty} \Psi_j$ are the long-run cumulative responses to, respectively, reduced-form and structural shocks.

Moreover, if $y_t = \Delta x_t$, $\Theta(1)$ and $\Psi(1)$ measure the long-run response of the variables in $x_t$ (levels).

A **long-run identification strategy** imposes restrictions on $\Psi(1)$.

### How can we compute $\Theta(1)$?

For a VAR(1), recall that $\Theta_j = \Phi^j$. Thus,
$$\Theta(1) = \sum_{j=0}^{\infty} \Theta_j = \sum_{j=0}^{\infty} \Phi^j = (I - \Phi)^{-1}$$

For a VAR(p), recall than using the companion form we obtained $\Theta_j = S \Phi^j S'$. Thus,
$$\Theta(1) = \sum_{j=0}^{\infty} S \Phi^j S' = S \left(\sum_{j=0}^{\infty} \Phi^j\right) S' = S(I - \Phi)^{-1} S'$$

### How do restrictions on $\Psi(1)$ can help to find $A_0$?

Assume for simplicity that $\Omega = I$. Then $\Sigma = A_0^{-1} [A_0^{-1}]'$.

Also, given that $\Theta(L)A_0^{-1} = \Psi(L)$, we have
$$\Theta(1)A_0^{-1} [A_0^{-1}]' \Theta(1)' = \Psi(1)\Psi(1)'$$
$$\Theta(1)\Sigma\Theta(1)' = \Psi(1)\Psi(1)'$$

The left-hand-side can be computed from the data. Notice also that this matrix is symmetric, so it has $\frac{m(m+1)}{2}$ unique elements.

Thus, for full identification we need $\frac{m(m-1)}{2}$ restrictions on $\Psi(1)$.

If these restrictions are recursive, we can solve for $\Psi(1)$ as the Cholesky factorization of $\Theta(1)\Sigma\Theta(1)'$.

Otherwise, we can use a minimum distance approach as we did with non-recursive short run restrictions.

Once we get $\Psi(1)$, we can compute $A_0 = \Psi(1)^{-1}\Theta(1)$.

In most softwares $\Psi(1)$ is defined as $C$.

### Warm-up example:

**Monetary shocks:** If $y_t = [\Delta gdp_t, \Delta m_t]'$, under long-run money neutrality the long run response of $gdp_t$ to a monetary policy shock should be zero. This is equivalent to assume that

$$C = \begin{bmatrix} c_{11} & 0 \\ c_{21} & c_{22} \end{bmatrix}$$

Thus, the second shock is the monetary-policy shock.

### Application: Nominal and real shocks and the exchange rate

Enders and Lee (1997): Let $y_t = [\Delta rer_t, \Delta ner_t]$. Identification assumption: long-run money neutrality. Nominal shocks have no long-run effects on the RER.

This implies
$$C = \begin{bmatrix} c_{11} & 0 \\ c_{21} & c_{22} \end{bmatrix}$$

Then, the second shock is the nominal shock.

### Application: Demand and Supply shocks

Blanchard and Quah (1989): Let $y_t = [\Delta gdp_t, ur_t]$.

**Assumption:** Demand shocks have no long-run impact on gdps.

This implies
$$C = \begin{bmatrix} c_{11} & 0 \\ c_{21} & c_{22} \end{bmatrix}$$

Then, the second shock is the demand shock.

Fuentes, Gredig and Larrain (2008) apply this to Chile.

### Revisiting the ERPT

**Usual ERPT:** based on a "surprise"/"unforecastable" NER shock.

However, not all shocks are alike. If there is more than one shock that can move the NER, then we can define as many **conditional** ERPT as structural shocks we want to consider. This is the same ratio of IRFs, but conditional on a given shock.

García-Cicco & García-Schmidt (2020) show that the **unconditional** ERPT is a weighted average of all **conditional** ERPTs.

**Application:** Why have countries under IT regimes experienced a decrease their unconditional ERPTs?
- From Enders and Lee (1997): compute nominal and real ER shocks.
- The nominal shock is interpreted as changes to long-run inflation "target."
- We will see that IT countries reduced the frequency of these shock, obtaining a smaller **unconditional** ERPT.

IT countries reduced the ERPT by:
- Generating nominal shocks less frequently.
- Smoothing the inflationary effects of real shocks.

## Other tools to interpret SVARs

### Forecast error variance decomposition

The forecast error can be written in terms of the structural errors as
$$y_{t+h} - y_{t+h|t} = \sum_{j=0}^{h-1} \Psi_j u_{t+h-j}$$

Example, with a VAR(1) $y_t = \hat{\Phi}_1 y_{t-1} + e_t$. Then,
$$y_{t+h} = \Phi_1 y_{t+h-1} + e_{t+h} = \Phi_1(\Phi_1 y_{t+h-2} + e_{t+h-1}) + e_{t+h} = (\Phi_1)^h y_t + \sum_{j=0}^{h-1} (\Phi_1)^j e_{t+h-j}$$

and, applying expectations, $y_{t+h|t} = (\Phi_1)^h y_t$.

Then
$$y_{t+h} - y_{t+h|t} = \sum_{j=0}^{h-1} (\Phi_1)^j e_{t+h-j} = \sum_{j=0}^{h-1} \Theta_j e_{t+h-j} = \sum_{j=0}^{h-1} \Psi_j u_{t+h-j}$$

We can compute $V(y_{t+h} - y_{t+h|t})$. Given i.i.d. shocks, we have
$$V(y_{t+h} - y_{t+h|t}) = \sum_{j=0}^{h-1} \Psi_j \Omega \Psi_j'$$

Moreover, as $\Omega$ is diagonal we can write,
$$V(y_{t+h} - y_{t+h|t}) = \sum_{j=0}^{h-1} [\Psi_j]_{:,1} \omega_1 [\Psi_j]_{:,1}' + ... + \sum_{j=0}^{h-1} [\Psi_j]_{:,m} \omega_m [\Psi_j]_{:,m}'$$

where $\omega_i$ is the $i$th element in the diagonal of $\Omega$.

We can decompose the forecast error variance in parts: one for each shocks. This is called the **FEVD**.

Notice that we cannot do this with the reduced-form shocks $e_t$.

If the variables in $y_t$ are I(0), when $h$ tends to infinity this decomposition is equivalent to the decomposition of the unconditional variance of $y_t$.

In practice, we don't know $\Psi_j$ but we can calculate $\hat{\Psi}_j$. Thus the FEVD will also be uncertain, so we need inference about them.

The same three methods we described for the IRFs can be used to compute confidence bands for FEVD. In particular, Montecarlo and Bootstrap are generally preferred because the asymptotic distribution of the FEVD is not easy to characterize analytically.

### Historical decomposition

Using the companion form we can write
$$y_t = \sum_{j=0}^{t} \Psi_j \Pi + \Phi^t Y_0 + \sum_{j=0}^{t} \Psi_j u_{t-j} = \sum_{j=0}^{t} \Psi_j \Pi + \Phi^t Y_0 + \sum_{i=0}^{m} \left(\sum_{j=0}^{t} [\Psi_j]_{:,i} u_{i,t-j}\right)$$

where $[\Psi_j]_{:,i}$ is the $i$th column of the matrix $\Psi_j$.

At a given $t$, $y_t$ is the sum of the influence of deterministic terms, initial conditions, and the contribution of each structural shock (and its past).

We can compute counterfactual historical paths with respect to the shocks.

Inference can also be performed by the methods previously described.
