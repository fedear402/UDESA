## Introduction

- We usually seek to estimate conditional expectations (forecast, IRF).
- Usual approach: model the joint dynamics of all the relevant variables, and compute any conditional expectation with it (e.g. VARs).
- Alternative: Estimate the conditional expectation of interest directly.
- Key result: If our goal is estimate $E(y|x)$, the "best" (in a mean-squared error sense) linear prediction is provided by the linear regression model (i.e. $\hat{\beta}x$, the orthogonal projection of the variable $y$ on the space spanned by the elements of the vector $x$).

---

## Forecast

- Forecast: $E\{x_{T+h}|\mathcal{I}_{T-1}\}$, where $\mathcal{I}_{T-1} = [y_{T-1}, y_{T-2}, ...]$, $y_t$ are all relevant variables, and $x_t \in y_t$.

- Using VAR with companion form $y_t = \Phi y_{t-1} + e_t$ we have
  $$E\{x_{T+h}|\mathcal{I}_{T-1}\} = E\{x_{T+h}|y_{T-1}\} = S(\Phi)^{h+1}y_{T-1}$$
  where $S$ is a selection matrix such that $x_t = Sy_t$. This is called *iterated forecast*.

- Direct estimation of conditional expectation with linear regression:
  $$x_{t+h} = \beta_h y_{t-1} + \epsilon_{t+h} \Rightarrow E\{x_{T+h}|y_{T-1}\} = \beta_h y_{T-1}$$
  This is called *direct forecast*. Some comments:
  - Requires one regression for each horizon $h$ of interest.
  - Can easily add strictly exogenous components (e.g. constant).
  - We don't need to use the same number of lags for all variables:
    $$x_{t+h} = \beta_h(L)y_{t-1} + \epsilon_{t+h} \Rightarrow E\{x_{T+h}|\mathcal{I}_{T-1}\} = \beta_h(L)y_{T-1}$$

### Comparison:

- If VAR is the true DGP both are asymptotically equivalent. In short samples, iterated forecast are more efficient for large $h$.
- If the VAR is not the true DGP, iterated forecast might be either inconsistent or inefficient.
- Direct forecast (with appropriate lag selection) will be consistent as long as the true model is linear. If the true DGP is not linear, it still provides the best asymptotic linear approximation (in a mean-squared-error sense).
- VAR models are generally "squared" (once you choose the lag, all variables are included). The direct forecast method explicitly considers that this may not be the case.
- The VAR model allows to forecast all variables in $y_t$. A direct forecast for one variable in $y_t$ says nothing about other variables.
- Inference is simpler with the direct method.

## IRF-Local Projections

- $IRF_{x,s}(h) \equiv E(x_{T+h}|\mathcal{I}_{T-1}, u^s_T = 1) - E(x_{T+h}|\mathcal{I}_{T-1})$, where $u_t$ are structural shocks. $x_t, y_t, \mathcal{I}_t$ are the same as before.

- Structural VAR: $u_t = A_0 e_t$ ($e_t$ are reduced-form residuals). Then,
  $$IRF_{y,u}(h) = \Theta_h (A_0)^{-1} \Rightarrow IRF_{x,s}(h) = [\Theta_h (A_0)^{-1}]_{\{x,s\}}$$
  where $\Theta_h$ is the reduced-form VMA($\infty$) (e.g. in VAR(1), $\Theta_h = (\Phi_1)^h$).

- Local Projection: suppose we observe $u_{s,t}$. Run the regression
  $$x_{t+h} = \beta_h u_{s,t} + \epsilon_{t+h} \Rightarrow IRF_{x,s}(h) = \beta_h$$

Some comments:
- Both alternatives are asymptotically equivalent.
- Requires one regression for each horizon $h$ of interest.
- Residuals $\epsilon_{t+h}$ will likely be auto-correlated (more later).

### Detailed Local Projection Approach

- It is convenient to derive an expression that depends on observables. Recall the reduced form: $y_t = \Phi_1 y_{t-1} + e_t$, then
  $$u_t = A_0 e_t = A_0(y_t - \Phi_1 y_{t-1}) \Rightarrow u_{s,t} = a_s e_t = a_s(y_t - \Phi_1 y_{t-1})$$
  where $a_s$ is the row of $A_0$ corresponding to the position of $s$.

- Local projection regression
  $$x_{t+h} = \alpha_h + \beta_h(a_s y_t) + \gamma_h y_{t-1} + \epsilon_{t+h} \Rightarrow IRF_{x,j}(h) = \beta_h$$

- Without imposing the same lags: $x_{t+h} = \alpha_h + \beta_h(a_s y_t) + \gamma_h(L)y_{t-1} + \epsilon_{t+h}$.

- If $A_0$ is lower triangular and...
  - $s_t$ is ordered first, $a_s = [1\ 0\ 0\ ...]$, so: $x_{t+h} = \alpha_h + \beta_h s_t + \gamma_h(L)y_{t-1} + \epsilon_{t+h}$
  - $r_t$ are the variables before $s_t$: $x_{t+h} = \alpha_h + \beta_h s_t + \delta_h r_t + \gamma_h(L)y_{t-1} + \epsilon_{t+h}$
  - Can you see the Frisch-Waugh-Lovell (FWL) theorem here?

### Comments:

- Distinctions between VAR vs LP are independent from identification issues.
- Only in the recursive case you don't need a previous estimate of $a_s$.
- Asymptotic equivalence holds as in the forecast case.
- Short-sample trade off: If VAR is the true model, VAR-IRF are more efficient than LP-IRF. If VAR is misspecified, VAR-IRF will be biased.
- LP allow for more flexibility in the amount of lags involved; although this is relevant only for efficiency, not consistency.

## Inference

- If the VAR is the true model, in the regression
  $$x_{t+h} = \alpha_h + \beta_h(a_s y_t) + \gamma_h y_{t-1} + \epsilon_{t+h},$$
  the residuals feature auto-correlation
  $$\epsilon_{t+h} = S[e_{t+h} + ... + e_{t+1} + e_{\sim s,t}]$$
  where $e_{\sim s,t}$ is the part of $e_t$ orthogonal to $u_{s,t}$, and recall $S$ is such that $x_t = Sy_t$.

- Alternatives:
  - Use HAC (Newey-West) standard errors.
  - Lag-augmentation (Montiel-Olea & Plagborg-Moller, 2021): run the regression with an additional lag than the one included in the VAR.
  - Bootstrap: Estimate a reduced form VAR, use it the generate $M$ bootstrapped samples, and estimate the LP for each of them.
  - Smooth local projections (Barnichon & Brownlees, 2019): generalized Ridge estimator to shrink the sequence $\beta_h$ to a polynomial function on $h$ (in the extreme, this is equivalent to a VAR).

## Beyond VARs

- Suppose you observe the shock $u^s_t$ directly, which in particular implies that $u^s_t$ is i.i.d. Consider two alternative regressions,
  $$x_{t+h} = \alpha_h + \beta_h u^s_t + \epsilon_{t+h}, \quad \text{and} \quad x_{t+h} = \alpha_h + \beta_h u^s_t + \gamma_h(L)y_{t-1} + \epsilon_{t+h}.$$

- Comparison:
  - Both will $\beta_h$ and $\beta_h$ consistently estimate $IRF_{x,s}(h)$. Why? If $u^s_t$ is i.i.d. and is independent from other shocks, then $E(\epsilon_{t+h}|u^s_t) = 0$; which is the only requirement for consistency.
  - The second equation can improve efficiency (recall lag augmentation).

- Recall the case we saw before, with $s_t$ ordered first,
  $$x_{t+h} = \alpha_h + \beta_h s_t + \gamma_h(L)y_{t-1} + \epsilon_{t+h}$$
  Here, the role of the lags is different: as in general $s_t$ is not i.i.d., the inclusion of lags is relevant to compute the response to the unanticipated component (recall FWL theorem). In other words, if $s_t$ is not i.i.d. and we estimate $x_{t+h} = \alpha_h + \beta_h s_t + \epsilon_{t+h}$, $\beta_h$ does not estimate $IRF_{x,s}(h)$.

- This comparison is relevant to understand the role that "controls" play in local projections: to identify the shock or to improve efficiency.

## Extensions: Instrumental Variables, Panel

### IV:
Assume now that we want to estimate the responses to $s_t$, but the identification assumption doesn't come from short-run constraints but instead we have an instrument $z_t$. In this case we can estimate the regression;
$$x_{t+h} = \alpha_h + \beta_h s_t + \gamma_h(L)y_{t-1} + \epsilon_{t+h}$$
by IV, using $z_t, y_{t-1}, y_{t-2}, ...$ as instruments. Notice the original IRF that we compared with the VAR's is equivalent to estimating this equation setting $z_t = a_s y_t$ as the instrument.

### Panel:
We can easily extend the LP analysis to a panel setting
$$x_{i,t+h} = \alpha_{i,h} + \delta_h t + \beta_h s_{i,t} + \gamma_h(L)y_{i,t-1} + \epsilon_{i,t+h}$$

- Autocorrelation in residuals also needs to be considered. Driscoll–Kraay is the panel version of Newey-West. No results yet on lag augmentation for Panel LP.

## Transformations of IRFs

- VAR inference about cumulative IRFs, or ratios of IRF, is cumbersome (e.g. it requires bootstrap). With LP is simpler.

- Cumulative IRF: let $cx_{t,h} = \sum^h_{j=0} x_{t+j}$, estimate
  $$cx_{t,h} = \alpha_h + \beta_h(a_s y_t) + \gamma_h(L)y_{t-1} + \epsilon_{t+h}$$
  If $x_t = w_t - w_{t-1}$, this is equivalent to
  $$w_{t+h} - w_{t-1} = \alpha_h + \beta_h(a_s y_t) + \gamma_h(L)y_{t-1} + \epsilon_{t+h}$$

- If we are interested in the ratio of two cumulative IRFs (of, say, variables $x, f \in y$) to the same shock $s$ (e.g. ERPT), estimate by IV
  $$cx_{t,h} = \alpha_h + \beta_h(cf_{t,h}) + \gamma_h(L)y_{t-1} + \epsilon_{t+h}$$
  using $a_s y_t$ as the instrument for $cf_{t,h}$ (try to prove this assuming no lags and no constant, using the algebra of 2SLS).

## Exploring Non-linearities

- Suppose you think the IRF should be different if a variable $q_t > \bar{q}$, relative to when $q_t \leq \bar{q}$, assuming $q_t$ is weakly exogenous and that $\bar{q}$ is known. Examples: asymmetric responses, big vs small shocks, effects conditional on the stage of the cycle, etc.

- This cannot be implemented with a VAR, due to linearity.

- LP: define $D_t = 1$ if $q_t > \bar{q}$ and $D_t = 0$ otherwise. We can run
  $$x_{t+h} = D_t[\alpha_{1h} + \beta_{1h}(a_s y_t) + \gamma_{1h}(L)y_{t-1}] + (1-D_t)[\alpha_{0h} + \beta_{0h}(a_s y_t) + \gamma_{0h}(L)y_{t-1}] + \epsilon_{t+h}$$
  $\beta_{1h}$ is the IRF if $q_t > \bar{q}$, and $\beta_{0h}$ if $q_t \leq \bar{q}$.

- Easily generalized to more than one conditional.
- Using $q_t = t$ and $\bar{q} = \tau$ for $\tau \in [1,T]$, this allow to consider differences by sub-periods.
- Theoretical basis for these approaches is yet not clear (no obvious DGP to compare with).

## Application: Fiscal Multiplier

- Fiscal multiplier: for each additional dollar spent by the government, how much does GDP changes (all measured in constant monetary units).

- Let $G_t$ and $Y_t$ denote gov. expenditure and GDP (in real terms):
  $$M(h) = \frac{E_{t-1,G}(Y_{t+h} - Y_{t-1}) - E_{t-1}(Y_{t+h} - Y_{t-1})}{E_{t-1,G}(G_{t+h} - G_{t-1}) - E_{t-1}(G_{t+h} - G_{t-1})}$$
  where $E_{t-1}(x_{t+h}) = E(x_{t+h}|\mathcal{I}_{t-1})$ and $E_{t-1,G}(x_{t+h}) = E(x_{t+h}|\mathcal{I}_{t-1}, u^G_t = 1)$.

- Why is it important to divide by the evolution of $G_{t+h}$?
- We first need to identify $u^G_t$. We already saw the Blanchard-Perotti approach; see Ramey and Zubairy (2018) for others.
- We will see it is not obvious to compute $M(h)$ using VARs.

### VAR Approach Issues

- VARs use variable in logs, $g_t = \ln(G_t)$ and $y_t = \ln(Y_t)$, using differences (difference of variables in levels are generally not stationary).

- With this, the ratio of cumulative responses is
  $$\frac{E_{t-1,G}(y_{t+h} - y_{t-1}) - E_{t-1}(y_{t+h} - y_{t-1})}{E_{t-1,G}(g_{t+h} - g_{t-1}) - E_{t-1}(g_{t+h} - g_{t-1})}$$

- Using $g_{t+h} - g_{t-1} \approx \frac{G_{t+h}}{G_{t-1}} - 1$ and $y_{t+h} - y_{t-1} \approx \frac{Y_{t+h}}{Y_{t-1}} - 1$, the ratio is
  $$\frac{\frac{E_{t-1,G}(Y_{t+h})-E_{t-1}(Y_{t+h})}{Y_{t-1}}}{\frac{E_{t-1,G}(G_{t+h})-E_{t-1}(G_{t+h})}{G_{t-1}}} = \left[\frac{E_{t-1,G}(Y_{t+h}) - E_{t-1}(Y_{t+h})}{E_{t-1,G}(G_{t+h}) - E_{t-1}(G_{t+h})}\right]\frac{G_{t-1}}{Y_{t-1}}$$
  The first part is $M(h)$, but the second is not desired. Usual fix: multiply the ratio of cumulative responses by $\bar{Y}/\bar{G}$. But this can be a bad solution if this share is not stable.

### LP Approach

- LP approach: Define $\tilde{g}_{t+h} = \frac{G_{t+h}-G_{t-1}}{Y_{t-1}}$ and $\tilde{y}_{t+h} = \frac{Y_{t+h}-Y_{t-1}}{Y_{t-1}}$.

- Blanchard-Perotti assumption: $\tilde{g}_t$ is ordered first.

- Cumulative response of $Y$
  $$\tilde{y}_{t+h} = \alpha_h + \beta_h \tilde{g}_t + \gamma_h(L)k_{t-1} + \epsilon_{t+h}$$
  where $k_{t-1}$ includes $\Delta g_{t-1}, \Delta y_{t-1}$ and other controls.

- Why does it work? The denominator is the same in $\tilde{g}_t$ and $\tilde{y}_{t+h}$, and independent from the shock, so it cancels out.

- To compute the multiplier, we use IV:
  $$\tilde{y}_{t+h} = \delta_h + \theta_h \tilde{g}_{t+h} + \psi_h(L)k_{t-1} + \upsilon_{t+h}$$
  using $\tilde{g}_t$ as the instrument for $\tilde{g}_{t+h}$.

- Ramey and Zubairy also consider responses conditional on unemployment in $t-1$.

## Conditional Effects

- Suppose we want to see if the response of $x$ to a shock in $s$ depends on how a third variable $w$ reacts to the shock.

- Cloyne et al (2003): Exploit the panel dimension
  $$x_{i,t+h} = \alpha_{i,h} + \delta_h t + \beta_h s_{i,t} + \delta_h s_{i,t}(w_{i,t+h} - \bar{w}_{i,h}) + \gamma_h(L)y_{i,t-1} + \epsilon_{i,t+h}$$
  Standard IRF: $\beta_h$. Marginal effect if $w_{i,t+h} - \bar{w}_i = w$: $\delta_h w$ (Constraining effect on IRF).

- $w_{i,t+h}$ is clearly endogenous. If $s_{i,t}$ is exogenous, we can use a 2-steps IV procedure:
  1. Estimate by LP the response of $w$ for each country:
     $$w_{i,t+h} = a_{i,h} + b_{i,h} s_{i,t} + g_{i,h}(L)y_{i,t-1} + v_{i,t+h}, \quad \text{for each } i.$$
     (notice this is not a panel). Compute $\hat{b}_{i,h}$ for each $i$.
  2. Estimate:
     $$x_{i,t+h} = \alpha_{i,h} + \delta_h t + \beta_h s_{i,t} + \delta_h s_{i,t}(\hat{b}_{i,h} - \bar{\hat{b}}_h) + \gamma_h(L)y_{i,t-1} + \epsilon_{i,t+h}$$

- Application: Effect of fiscal consolidation depending on monetary-policy accommodation.
